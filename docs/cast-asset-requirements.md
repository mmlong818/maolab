# 卡司立绘资产需求

日期：2026-07-03

本文件定义老师、学生和学科立绘的资产矩阵。它是 `docs/course-generation-design-requirements.md` 中角色立绘规则的细化版。

## 1. 资产分类

### 1.1 基础卡司立绘

用于课堂对白、RPG 半身立绘、老师讲解、学生追问和反馈场景。

基础卡司包含：

- 所有预设老师。
- 所有预设学生。

每个角色都必须按以下矩阵生成：

| 维度 | 取值 | 要求 |
| --- | --- | --- |
| 学段 | 小学、初中、高中 | 同一角色保持身份连续，但成熟度、表情夸张度和服装气质要符合学段。 |
| 季节服装 | 夏季、秋季 | 同一学段下至少两套服装；夏季更轻便，秋季更有层次。 |
| 表情 | neutral、happy、thinking、surprised | 四种表情必须保持同一角色脸型、发型、身材比例和服装设定。 |

也就是说，每个基础角色至少需要：

`3 个学段 × 2 套季节服装 × 4 种表情 = 24 张半身脱底立绘`

## 2. 学科立绘

学科立绘用于封面、学科氛围、章节起始页和学科专属装饰，不直接承担课堂对白表演。

学科立绘同样需要按学段和季节生成：

| 维度 | 取值 | 要求 |
| --- | --- | --- |
| 学科 | 语文、数学、英语、物理、化学、生物、历史、地理等已启用学科 | 按学科气质加入合理服装细节、道具或姿态。 |
| 学段 | 小学、初中、高中 | 角色成熟度和课堂可信度必须匹配学段。 |
| 季节服装 | 夏季、秋季 | 与基础卡司服装系统一致。 |
| 表情 | 仅 neutral | 学科立绘不要求多表情，避免资产规模失控。 |

学科立绘不得替代基础卡司对白立绘。进入对白系统时，必须使用基础卡司立绘矩阵中的半身脱底 PNG。

## 3. 文件命名

新增资产采用以下路径，不再继续扩展旧的散乱目录：

```text
app/public/generated-images/cast/base/{schoolStage}/{season}/{characterId}-{expression}.png
app/public/generated-images/cast/base/{schoolStage}/{season}/{characterId}-{expression}.json

app/public/generated-images/cast/subject/{subject}/{schoolStage}/{season}/{characterId}.png
app/public/generated-images/cast/subject/{subject}/{schoolStage}/{season}/{characterId}.json
```

字段取值：

- `schoolStage`: `primary`、`middle`、`high`
- `season`: `summer`、`autumn`
- `expression`: `neutral`、`happy`、`thinking`、`surprised`
- `characterId`: 项目内稳定角色 ID，例如 `teacher-xiaomei`、`teacher-professor`、`student-mei`

## 4. 画面标准

所有运行时立绘必须满足：

- PNG，透明背景。
- 推荐画布 `1024 × 1536`。
- 半身构图，至少包含头部、肩部、胸口到腰部的可识别身体比例。
- 不使用头像框、圆形头像、方形背景、纸张背景或整图插画背景。
- 同一角色跨表情、学段、服装必须保持可识别身份；允许年龄感变化，但不能像换了一个人。
- 角色边缘干净，无明显抠图毛边、残留背景色、文字、水印、UI 元素。
- 不遮挡教学画面的诗句、题干、图像主体、关键标注和正在讲解的证据。

## 5. 运行时选择规则

1. 对白和授课表演优先使用基础卡司立绘：
   `characterId + schoolStage + season + expression`
2. 封面和学科氛围页可使用学科立绘：
   `subject + characterId + schoolStage + season`
3. `season` 只能由后台在真实授课入口按当时日期判断一次并写入课程数据；前端不得用本地时间自行切换季节。
4. 当前映射规则：5-9 月使用 `summer`，10-4 月使用 `autumn`。
5. 学科立绘没有多表情，不参与 `emotion` 驱动。
6. 缺少所需基础立绘时，不允许退回旧头像或带背景整图；必须记录为资产缺口。
7. 缺少学科立绘时，可以临时使用基础卡司 neutral 立绘，但该课程应记录为学科资产缺口。

## 6. 审查标准

资产进入项目后必须至少检查：

- 尺寸是否符合 `1024 × 1536` 或明确登记例外。
- 是否有 alpha 通道，四角是否透明。
- 非透明内容边界是否接近半身比例，而不是头部特写。
- 同一角色四种表情是否脸型、发型、服装、比例一致。
- 小学、初中、高中版本是否有合理成熟度差异。
- 夏季、秋季服装是否明显不同，但不改变角色身份。
- 学科立绘是否只做学科氛围，不混入多表情对白系统。

## 7. 现有资产处理

`cast/cutouts/`、`cast/teachers/` 和各学科旧目录已经退出运行路径：

- 不允许作为课堂回退图。
- 不允许作为新代码路径或新课程数据路径。
- 不合格项包括：学生只有头部、老师 neutral 与其他表情风格不一致、带米色背景的整图、不同表情比例差异过大。

后续批量生成时，应优先补齐基础卡司矩阵，再补学科立绘矩阵。
