## 本轮发现与根因修复

1. **备课页出现虚假阻断。** 页面先行课程仍叠加审计已经废弃的旧场景数据，导致每页产生三条无关阻断。备课摘要和发布判定现只审计正式 `pageContent.pages`，旧课程才走兼容链。
2. **讲解页有图但客户端不显示。** 发布判定能看到 `imageUrl`，讲解页渲染器却忽略该字段。讲解页现支持图文并排；无图页面保持原布局。
3. **物理受力图与文字不一致。** 原位图没有清楚标出 `F1/F2`，箭长也不能表达 `5 N` 大于 `3 N`。已换为确定性 SVG，方向、共线、作用对象、标签和箭长与题意严格一致。
4. **解释页内容过密。** 语文、英语、物理、化学、道德与法治各有一页把教师讲解压入学生页面。学生页已压缩为本页必要信息，细节保留在教师讲稿；共享审计增加解释页容量门槛。
5. **课程边界不严谨。** 生物标题承诺“倒像”但正文只讲放大倍数；地理混淆“读数顺序”和“定位顺序”；科学把所有自相似都说成严格相同；道德与法治对权利义务关系的边界表述错误。以上均已修正，并分别进入生成提示或确定性审计规则。
6. **来源引用在压缩时丢失。** 《芣苢》解释页压缩后遗漏原文来源标记，发布门禁正确阻断；现已恢复引用，并保留版本一致性检查。
