特殊内容呈现 · 英语学科画廊

英语,不该只是背单词表。
让语言的形式本身变成可视化的一等公民。

发音、词形、句法结构本身就是要学的东西 —— 不是知识的容器。六类内容、每类两个结构真异质的方向,参照系是 Duolingo 的声音质感、语音学教材的口腔剖面图、代码 diff 高亮、地铁线路图,而不是双语词典的密排小字。

音 · 形 · 义,三位一体的记忆单元

音(发音)-形(拼写)-义(释义/例句)绑定成一个被认真设计过的「物件」,而不是词典条目里的一行小字。

方向甲 · 声波卡 SoundCard

音标画成重音节奏条

IPA 不再是括号里的一串小符号,而是按音节切分的"音高波形"——重读音节更大更深,弱读音节缩小变浅。词性做成强调色小圆点,例句沉在灰卡里、目标词描边高亮。

方向乙 · 词族矩阵 WordFamilyGrid

一课时的词,同屏看见系统位置

结构真异质——不做单卡片,把 5-8 个生词按词性/语义场铺成网格,当前词高亮聚焦,其余弱化为背景。学生看到的是"这个词在词汇系统里的位置",而非孤立卡片。

低小 1–2

张嘴形状 + 大插画

不出现音标符号,用拟人化嘴型插画配大图配词,例句 3 词以内。

高小 3–6

声波卡完整 + 小组词族

大插画仍主导视线,声波卡完整上线;词族矩阵缩到 3-4 词的小组。

初中 7–9

去插画,留节奏条

声波卡只留抽象节奏条+重音标记;词族矩阵按词性/语义场完整分组。

高中 10–12

纯音高示意 + 搭配网络

声波卡克制为纯音高/重音图,无装饰;词族矩阵扩展到搭配网络并标词源。

02 / 音标 IPA

发音器官的动作,不是一张音标表

音位区分 + 发音器官动作(舌位、唇形、清浊),而不是记住一张学术分类的黑白方格矩阵。

元音落在标准舌位梯形图对应坐标,辅音按发音部位×方式排成棋盘,格子按清浊配对着色。参照医学解剖信息图与乐器指法图的精密质感。

方向乙 · 对立对卡组 MinimalPairs Deck

不背音标表,只听辨"差在哪"

结构真异质——用最小对立对左右并置,中间一条"差异轴"可视化具体差异。版式像相机参数评测图,是当代听辨教学(minimal pair drills)的主流范式。

低小 1–2

不出现音标符号

只用嘴巴张合程度的拟人化插画做自然拼读(phonics)启蒙。

高小 3–6

高频音标 + 大插画嘴型

引入少量高频音标,对立对只挑最直观的几组(如长短元音)。

初中 7–9

剖面图 + 矩阵完整上线

标准舌位梯形图+全套辅音矩阵完整呈现,对立对进入系统练习。

高中 10–12

学术精确,不做装饰

舌位坐标对应国际语音学标准值,矩阵含清浊/送气标注,克制无插画。

03 / 语法与时态

时态是运动轨迹,不是背诵表格

时态 = 动作相对说话时刻在时间轴上的位置(点/区间)+ 体(进行/完成)的结构公式,把抽象语法变成可感知的运动。

PastNowFuture
现在完成时have/has + p.p.
She has visited Paris three times.
现在进行时am/is/are + V-ing
She is visiting Paris now.
base · visit-ing · visitingp.p. · visited
方向甲 · 时间光轨 Timeline Ray

动作画成一条会发光的轨迹

时态是横向"时间光轨"——现在完成时是从过去延伸到现在、末端发亮的一段轨迹;进行时是"此刻正在扩散"的圆环。类比音乐播放进度条/游戏进度可视化。

方向乙 · 时态积木 Tense Blocks

只高亮"变了的那一块"

结构真异质——语法公式的每个成分做成固定形状+固定色的积木(助动词=六边形、动词=矩形),两个时态并排陈列,只描边标出差异。像代码 diff 高亮、乐高说明书。

低小 1–2

三个点,不出现公式

时间光轨最简版——过去/现在/将来三个点,配"昨天/现在/明天"生活化插画。

高小 3–6

四种时态 + 贴纸积木

时间光轨覆盖四种基本时态,积木隐喻以贴纸形式初现(如 help→helped)。

初中 7–9

积木 diff + 完整体貌

时态对比用积木 diff 呈现,时间光轨标注完整体貌(进行/完成)。

高中 10–12

双轨对照,标语域差异

积木 diff + 时间光轨双轨对照,标注正式度差异,配色学术克制。

04 / 句型结构

成分的功能角色,而不是下划线图例

识别主谓宾定状补的功能角色,是造句与写作的地基能力——信息密度要够高,但不需要图例才能读懂。

方向甲 · 句法频谱条 Syntax Spectrum Bar

颜色 + 长度直接编码语法功能

逐词像均衡器一样横排,每个词下方一条色带表示成分角色,色带长度=词数。多例句纵向左对齐,一眼看出句型模式的重复与变化。

方向乙 · 句子解剖卡 Sentence X-Ray

抽屉式标注,从整体到部件

结构真异质——句子先浅色横排,再从成分下方"抽出"卡片按语法层级堆叠展开,定语从句嵌套在主语之下。模仿产品拆解信息图的展开方式,适合复合句教学。

低小 1–2

谁-做什么,两色+图标

只标主语/谓语两色,用人形图标代替术语,宾语视需要出现。

高小 3–6

频谱条三色 + 一层展开

频谱条主谓宾三色上线,解剖卡简化为一层展开。

初中 7–9

定状补上线,术语标准化

频谱条含定语/状语/补语,解剖卡多层展开,术语标准化。

高中 10–12

复合句嵌套,对比语序

解剖卡含从句嵌套层级展开,频谱条用于对比英汉语序差异。

05 / 对话与情景交际

识别交际功能,而不只是背台词

真实交际中的语用功能——寒暄/请求/协商/拒绝,让学生记住台词的同时,识别这段对话"在干什么"。

气泡骨架 + 情景条 + 功能徽章

保留双声道气泡骨架,顶部加情景条(emoji+场景设定),每句气泡追加语用功能徽章。改动成本最低——在既有气泡上叠加两层信息即可升级。

方向乙 · 情景剧场卡 Scenario Board

分镜卡片流,叙事而非记录

结构真异质——不用聊天气泡,改用横向分镜卡片流,卡片背景按情景轻微换色,强调"场景事件的推进"。类比专业分镜工具(如 Boords)的叙事感。

低小 1–2

大 emoji + 拟声词

情景条用大 emoji+拟声词,气泡超大配角色简笔画,不出现术语。

高小 3–6

中文功能徽章

情景条+简单功能徽章(如"打招呼"),气泡骨架保留。

初中 7–9

英文术语 + 剧场卡上线

功能徽章用标准英文术语,情景剧场卡上线替代纯气泡。

高中 10–12

语域标注,设计克制

标注礼貌层级(polite register),加入潜台词对比批注,设计克制。

方向乙 · 词源家族树 Etymology Tree

一个词根,衍生一整个词族

结构真异质——词根放在根部,派生词向外生长,枝干标注添加的前后缀。像 commit 树/知识图谱,强调生成关系而非并列列表。

低小 1–2

单词变形游戏插画

不做词素拆解,替换为具象的"单词变形游戏"(如加 -s 变复数)。

高小 3–6

两层积木 + 3-4 分支

积木塔简化为前缀+词根两层,家族树只展开 3-4 个分支。

初中 7–9

三层积木,标准家族树

完整积木塔(前缀-词根-后缀三层),家族树标准展开。

高中 10–12

跨语言词源,标构词能产性

家族树扩展到拉丁/希腊词源,积木塔标注该语素的构词能产性。
