特殊内容呈现 · 物理画廊

力、电流、光线、运动趋势——
看不见的东西，画得看得见，还经得起核验。

物理内容的专属命题：受力分析教矢量代数，电路图教拓扑关系，光路图教可计算的几何光学，运动图像教函数图像的物理意义。六类内容各给两个结构真异质的现代方向——错一个矢量方向、错一个电路符号、错一条光路，教学价值就归零，所以每张图都按真实物理量精确画出。

电路红线：中国教材电阻符号是国标长方形，不是欧美锯齿形；光路红线：反射角=入射角、折射角由 Snell 定律算出，均非自由绘图。

01 / 公式 · 物理量 · 单位

定量关系卡——公式不是背的符号串，是量与量的对应

符号、单位、数值三者能否对上号，决定学生是否建立了"量"的概念。示例：v = s / t，位移 s=100m，时间 t=20s，求速度 v。

量纲仪表读数带 · dimension ledger

v = ?速度 · m/s
=
s = 100位移 · m
/
t = 20时间 · s
已知量 given 待求量 unknown（虚线边框留白）
方向甲 · 量纲仪表读数带

公式变成一块可读的仪表面板

挪用工程制图尺寸标注线与仪表盘"数值即状态"隐喻；胶囊按角色配色，未知量虚线待求，不再是抄黑板。

每个节点旁挂"内联类型提示"（借代码编辑器 inline type hint 语言）
方向乙 · 推导轨道

公式呈现为过程，不是答案

横向节点轨道：定义 → 代入 → 化简，节点间箭头连接，回应"公式怎么来的"这个常年痛点。

  • 不出现字母符号

02 / 受力分析图 · 矢量的合成

力是矢量——方向、大小、合成规则必须精确

示例：木块静止于水平面，受力 mg=50N(270°)、N=50N(90°)、f=10N(180°)、F=20N(30°)。角度约定：物体右侧水平方向为 0°，逆时针为正。

木块静止于水平面 · 四力共同作用
重力支持力摩擦力拉力箭头=矢量本身，长度严格按比例，实心三角箭头（工程制图标准）
方向甲 · 工程受力蓝图

箭头是矢量本身，不是简笔画

起点在作用点、方向按角度、长度按比例；淡 CAD 网格纸质感，挪用工程力学制图 + 游戏引擎 Debug Draw。

合成分镜 · F1=30N(0°) 与 F2=40N(90°) 的合成
F1F2合力 R经典 3-4-5-50，∠=53°
方向乙 · 合成分镜

矢量合成是过程，不是终图

三格分镜：分力 → 平移作图 → 合力强调，借漫画分镜叙事语言呈现几何操作的过程性。

03 / 电路图 · 元件符号与拓扑

看懂连接关系——串并联判断是电学计算的先导语言

示例：电池 B1=6V，电阻 R1=5Ω 与 R2=10Ω 并联后与开关 S1 串联，开关闭合。电阻用国标长方形，不用锯齿形。

发光电路板 · S1 闭合，电流通路高亮
通路高亮（S1 闭合）电阻 = 国标长方形直角规范布线
方向甲 · 发光电路板

电流方向被看见，符号分毫不让

挪用 PCB/智能家居"通电即高亮"的视觉隐喻；断路部分会转灰虚化，通路发光，符号规范不让步。

模块拓扑网格 · 纵向=串联，同行=并联
R1/R2 同行并排 → 读出并联B1→[R1‖R2]→S1 纵向 → 读出串联
方向乙 · 模块拓扑网格

结构本身说话，不靠文字标注

借电路网表(netlist)/Node-RED 的模块化连线语言；不画连续导线，每个元件是独立模块卡。

低小 1–2

  • 不出现规范符号（超纲）
  • 强调闭合回路的直觉
高小 3–6

规范符号+圆角化，模块卡友好

  • 数值标注可选
  • 容错率高
初中 7–9

国标符号全面上线

  • 电流高亮强化"看得见"
  • 数值标注必须完整
高中 10–12

拓扑网格为主，极简黑白

桥式电路 · 多回路
  • 含电容/多回路

04 / 光路图 · 反射折射与成像

光线怎么走，决定像在哪——渲染器算，LLM 只给取值

折射示例：光从空气(n₁=1.00)射入玻璃(n₂=1.50)，入射角 θ₁=40°；由 Snell 定律 n₁sinθ₁=n₂sinθ₂ 算出 θ₂≈25°。凸透镜示例：物距 u=30cm，焦距 f=10cm（物在 2F 外），由 1/f=1/u+1/v 算出像距 v=15cm——像为倒立、缩小、实像，成在 F′与 2F′之间。

几何证明作图仪 · 折射（θ₁=40° → θ₂≈25°）
入射反射(θ=40°)折射(Snell 定律计算)
方向甲 · 几何证明作图仪

可以被复核的几何证明

法线短虚线+直角标记，关键角标精确数值；挪用精密仪器制图/GeoGebra 的作图美学，不是课本简笔画。

光线追踪剧场 · 凸透镜成像（u=30cm f=10cm → v=15cm）
玻璃半透明蓝色渐变材质三条特殊光线在像点精确汇聚
方向乙 · 光线追踪剧场

这东西真的在模拟光

挪用 CG 光线追踪调试可视化，发光光束+半透明玻璃材质，成像由薄透镜公式算出，架构上不会画错。

高小 3–6

  • 乙简化版：光束+镜面
  • 不标注角度数值
初中 7–9

  • 反射+平面镜/凸透镜成像
  • 虚像虚线、实像实线
高中 10–12

05 / 运动图像 · v-t / s-t

图像形状=运动性质——斜率、截距、面积都是物理量

示例运动：0–2s 匀加速 0→6m/s，2–5s 匀速 6m/s，5–8s 匀减速 6→0m/s。由此推出 s-t：(0,0)→(2,6m)→(5,24m)→(8,33m)。

运动仪表流 · v-t 图 + 事件锚点
加速匀速减速拐点=事件锚点标注（借 K 线图语言）
方向甲 · 运动仪表流

像读心电图一样读运动

转折点加"事件锚点"悬浮标注，阴影区域强调面积=位移；挪用金融图表/健康监测的图像叙事化手法。

多轨叠合乐谱 · v-t 与 s-t 同一时间轴对齐
v-t 轨s-t 轨竖向参考线=播放头，贯穿全部轨道
方向乙 · 多轨叠合乐谱

同一时刻，不同物理量的对应

借 DAW 多轨时间线语言，v-t 与 s-t 纵向堆叠对齐，精确传达运动学图像家族的微积分关系。

具象比较插画，不画坐标轴

  • 龟兔赛跑式"运动快慢"
  • 不引入坐标图
高小 3–6

极简坐标图，友好事件锚点

  • 事件锚点用友好图标 ⏸
  • 不引入加速度概念
初中 7–9

甲为主，匀速/变速是重点

面积=位移
  • 事件锚点标注规范化
  • v-t 面积定性强调
高中 10–12

乙多轨叠合为主，学术级规范

v-t / s-t / a-t 互推

06 / 实验装置图 · 控制变量的空间化

不是"这是个什么仪器"，是自变量→因变量的因果动线

示例：探究"弹簧测力计读数与钩码总重力"的关系——钩码通过定滑轮牵引测力计，理想情况下绳的张力（读数）等于钩码总重力。

实验台标注剖面 · 自变量(左) → 因变量(右)
读数 = 钩码总重力
自变量·钩码重力因变量·测力计读数图标化插画，非写实素描
方向甲 · 实验台标注剖面

空间位置暗示因果关系

左侧强调色=自变量器材，右侧强调色=因变量读数器材；挪用 PhET 一类现代科学模拟应用的图标化拆解语言。

变量控制看板 · 三栏结构，图退为点缀
控制变量
  • 滑轮组数量、绕线方式不变
  • 测力计使用前已校零
  • 绳与滑轮间摩擦不计
↕
操纵变量（自变量）
  • 钩码个数：1 → 2 → 3 个
  • 对应总重力：1N / 2N / 3N
观测变量（因变量）
  • 弹簧测力计读数
  • 对应记录：1.0N / 2.0N / 3.0N
结论：绳的张力（测力计读数）与所挂钩码的总重力大小相等
