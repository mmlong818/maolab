特殊内容呈现 · 数学画廊

竖式与坐标系,不该只是印刷时代的黑白工具图。
八类数学呈现,十六个超越教材的方向。

从位值制换算到方程推导链,每一类的视觉语法都由内容的本质结构决定——不是同一张卡片换皮。数字、比例、角度、坐标全部算对,参照 Brilliant.org 交互可视化与 3Blue1Brown 的动态直觉。

01 / 竖式计算

进位与借位,是位值制换算,不是书写规范

满十进一、借一当十——竖式的本质是一次单位换算正在发生,而不是数字被写进格子里的规矩。

方向甲 · 流光进位

位值仓水位上涨

每个数位是一座水位仓;个位仓满 10 后,溢出的部分化作光斑流向十位仓——进位被"看见发生",而不是被"写下一个小 1"。

方向乙 · 拆分卡

整十卡掰开成个位卡

数被拆成位值分量的实体卡片;借位时一张"整十卡"从阵列取出、掰开成十张个位卡落回——像乐高积木的拆解,而非格子里打斜杠改数字。

低小 1–2

拆分卡 + 食物/积木换算实物化,极低密度,只做一次运算。

高小 3–6

流光进位 / 拆分卡皆可,加验算步骤与过关式徽章。

初中 7–9

扩展到小数/多位数乘除,拆分卡收敛为规范位值网格,拟物退场。

高中 10–12

竖式基本退场,转为长除法/多项式除法的位值类比,极简排版。

02 / 分数与比例

部分—整体的关系,不是圆饼图配色

分数是平分后取几份;比例是两个量之间保持不变的比较关系——共享结构,服务不同问题。

面积切割 · 统一网格揭示公因数

方向甲 · 面积切割

统一网格的通分

正方形/圆形按分母精确等分,分子对应块高亮;异分母对比时叠加同一份数的网格,通分的"公因数"被直接看见。

比例天平 · 蜂蜜 : 水 = 3 : 4
90 : 120 = 3 : 4 ✓ 比例成立,天平配平
方向乙 · 比例天平

长度条挂在天平两端

两条色块长度条按题目比例伸缩;比例算对时天平配平,算错时天平倾斜——"比"是一种关系,而不是形状。

低小 1–2

具象食物切分(披萨/巧克力),鲜艳色块配极简数字。

高小 3–6

面积切割 + 比例条并用,异分母通分动画演示。

初中 7–9

比例天平扩展到百分比/负数比统计,编辑设计感环形图。

高中 10–12

收敛为函数比率的极简图表,代数结构优先于具象切割。

03 / 数轴

顺序、区间与距离,不是一条画好刻度的直线

数的大小关系、不等式解集、绝对值即"到 0 的距离"——数轴的信息量不该只压在开闭点这一处细节上。

地铁线路图 · 区间 [-2, 3)
方向甲 · 地铁线路图

站点即刻度,线路即区间

整数刻度是"站点",空心圆=不停靠(开区间)、实心圆=停靠(闭区间),区间是高亮的"线路段",可局部放大聚焦某段刻度。

弹性尺 · |−3| = |3| = 3
方向乙 · 弹性尺

回声波纹里的绝对值

负数区冷色、正数区暖色形成温度隐喻;绝对值表现为从 0 向两端等长扩散的回声波纹,直观呈现"距离"的对称性。

低小 1–2

数轴变"数字小路",角色沿路跳格子,只显示相关范围。

高小 3–6

地铁线路图引入,负数用温度计类比。

初中 7–9

不等式解集用区间高亮 + 开闭点规范符号上线。

高中 10–12

扩展为复合不等式/绝对值不等式的精密区间图,去除拟物装饰。

04 / 几何图形

辅助线是被显式添加的操作,不是一次性画完的线稿

空间关系与图形性质,辅助线是"揭示隐藏结构"的显式动作,证明是一条有先后顺序的逻辑链。

蓝图工程图 · 3-4-5 直角三角形,BD⊥AC
① 作 BD⊥AC 于 D —— 为构造两个相似直角三角形(射影定理)
方向甲 · 蓝图工程图

制图蓝 + 工程橙辅助线

原图实线用制图蓝,辅助线用工程橙虚线按证明步骤编号出现;角度用弧线+度数标签,标注用引线 callout,强调规范与顺序。

① 过 C 作 AB 的平行线 PQ
为什么:把 ∠A、∠B "搬"到 C 点比较
② 内错角相等
PQ∥AB 被 AC、BC 所截 → ∠1=α,∠2=β
③ 平角 = 180°
α + γ + β = 180°,即三角形内角和
方向乙 · 分层揭示

图形先成形,辅助线后叠加

图形本体先以完整实体呈现,辅助线作为叠加图层逐条淡入,每条辅助线附一句"为什么加这条线"的因果标注,强调证明的思路顺序。

低小 1–2

图形认知具象化(圆=披萨轮廓),无辅助线。

高小 3–6

简单边角度量,标注开始规范化,面积周长格子计数。

初中 7–9

标注体系全面上线,蓝图或分层揭示均可,强调证明步骤。

高中 10–12

扩展到解析几何/立体几何,精密排版,证明链完整呈现。

05 / 函数图像与坐标系

图像是映射关系的生成过程,不是方格纸上数出来的曲线

给定 x 如何决定 y,以及零点、极值、渐近线等关键结构——图像该被"画出来",而不是既定摆在那里。

动态描点 · y = x² − 2x − 3
方向甲 · 动态描点

点沿定义域滑动,轨迹渐渐连成曲线

3Blue1Brown 式:点沿 x 滑动,y 值实时计算并描出轨迹;坐标轴极简,只保留关键刻度,不铺满网格线——图像是"画出来的"。

渐近线 x = 2(垂直)
渐近线 y = 0(水平)
聚焦 x=0 → y=−0.5
y = 1x−2
方向乙 · 数据仪表盘

图像为主视觉,读数卡片侧边联动

坐标系设计成现代分析面板:图像本体为主视觉,零点/极值/渐近线作为侧边"读数卡片",随聚焦的 x 区间联动高亮更新。

低小 1–2

不作正式函数图像,身高/成长记录类简单折线,具象拟物。

高小 3–6

正比例关系图像(路程—时间),折线+情境点缀。

初中 7–9

一次/二次函数标准图像,坐标轴刻度开始严谨规范。

高中 10–12

扩展到三角/指数/对数函数,渐近线/极值点专业标注,拟物退场。

07 / 应用题(已知/求/解)

从情境抽取条件、建立模型,不是套哪个公式

已知/求/解三者不该混在一段文字里靠学生自己拆解——建模能力,而不是套公式的肌肉记忆。

案 №360
甲乙两地相距 360 千米,两车相向而行
证据①
甲车 90km/h
证据②
乙车 70km/h
待解之谜
几小时相遇?
推理链:设 t 小时后相遇 → 90t + 70t = 360 → 160t = 360 → t = 2.25
结案陈词:2.25 小时(2 小时 15 分)后两车相遇 —— 已验证 90×2.25+70×2.25=360 ✓
方向甲 · 案件卷宗

已知是证据,求解是结案陈词

侦探破案隐喻:题目是案件描述,已知条件是逐条揭示的证据卡片,步骤是推理链,结论是结案陈词。情绪驱动,呼应侦探人设基因。

已知→建模→求解→检验

工程/产品看板隐喻:已知条件是"输入参数卡",看板式分栏呈现"已知→中间量→答案"的推导路径,系统/逻辑驱动。

低小 1–2

案件卷宗简化为故事情境卡(买东西/分苹果插画)。

高小 3–6

两个方向轻量引入,已知条件卡片化,一到两步应用题。

初中 7–9

建模看板上线,覆盖方程组应用,设未知数→列方程→解→检验。

高中 10–12

扩展到数列/概率/导数应用,专业看板排版,卡通元素去除。

08 / 方程分步求解

每一步是合法操作,不是右侧写两个字"移项"

两边同加/同乘、移项变号——核心是推导链的因果性,与每一步操作为何仍保持等价。

3x + 5 = 20
− 5 两边同减 5
3x + 5 = 20
3x = 15
÷ 3 两边同除以 3
x = 5
方向甲 · 操作日志

每步等式是一条提交记录

代码 diff/版本控制视觉语言:每一步是一条"提交记录",高亮该步变化的项,可展开查看"合法性凭证"——强调可追溯性。

2x + 3 = 11 · 镜像折叠
2x
↕ 两边同减 3(镜像同步拿走 3 个单位)
2x
↕ 两边同除以 2(对折成两等份)
x=4
方向乙 · 镜像折叠

等号是镜线,两侧同步操作

等式两侧设计成以等号为镜线的对称面板,每次操作在两侧镜像同步执行——空间对称隐喻,直觉呈现"对称操作保持相等"。

低小 1–2

不作完整方程链,镜像折叠做「□+3=7」未知数猜谜的直觉引入。

高小 3–6

简单一元一次方程,镜像折叠为主,操作具象化(积木同步拿走)。

初中 7–9

操作日志/镜像折叠均可,覆盖二元一次方程组,移项变号显式标注。

高中 10–12

扩展到不等式/二次/指数对数方程,收敛为操作日志风格,拟物退场。
