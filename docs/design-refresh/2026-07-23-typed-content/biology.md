## 生物

> 定位延续 `2026-07-23-typed-content-forms-spec.md` §0.1–0.5:不做「教材第二版」。生物学科的五类专属内容——结构图解、生理流程、分类树、遗传图解、食物链/网——本质都是「**关系型信息**」(结构↔功能、阶段↔阶段、上位↔下位、亲代↔子代、捕食↔被捕食),教材把关系压平成黑白线图 + 编号表,我们要把关系的**拓扑本身**变成可读的现代图形语言。

### 结构图解(引线标注·结构-功能对应)

**教育内核**:结构决定功能——学生要记住的不是"这个部位叫什么",而是"叫这个名字的部位为什么长这样、干这件事"。结构名与功能必须**成对**出现,不能只考名词。

**要超越的教材形态**:灰阶示意图 + 直线引出线 + 底部编号对照表,引出线只指位置、不带功能信息,名称和功能割裂在图与文字表两处,需要来回对照。

**超越设计·方向甲【双层引标】**:在现有引线标注骨架(见"复用")上做信息层级升级——每个引线终点不再是"一行说明",而是一张**双区块 chip**:上区是结构名(accent 重音、大字号),下区是功能一句话(次级灰字),两者物理分层但同属一张卡,一眼分清"这是什么/这为什么"。引线从纯直线改为绕开图内容主体的轻曲线(贝塞尔),终端落在结构精确位置而非图边缘——现代医学解剖 App(Complete Anatomy 一类)的 callout 语法,比教材的"一条直线怼过去"精致但不炫技。

**方向乙【系统图层卡】**(结构真异质,非换皮):不用辐射引线,改用**图层导览**逻辑——底图是结构整体剪影大幅居中,侧边是一条横向"系统色带"(如循环系统标红、消化系统标蓝),点亮其中一段色带,图中对应结构区域联动高亮,该段色带下方浮现结构-功能卡组。这是"整体→按系统切片"的**层级降维**视角,和甲的"由图心向四周发散"是两种不同的空间关系(降维切片 vs 辐射标注),服务的教学动机也不同:甲适合"认识单个结构",乙适合"理解结构如何归入系统"。

**学段四档**:低小——具象大插画(卡通器官/动植物),结构≤3 个,chip 做成贴纸圆角,只讲"叫什么/像什么";高小——结构 4-5 个,乙方向做成"翻页揭层"游戏感,系统色带配小徽章;初中——甲乙皆可,结构 5-8 个,双层 chip 完整上线,系统色带开始出现多段;高中——甲乙皆可,结构 8+ 个,功能句改为机制短句(如"肾小球:滤过血浆生成原尿"),色带分段精细、克制无装饰。

**数据结构建议**:`contentSlots.structureCallouts`,每行 `结构名|功能一句话|所属系统(可选)`,如:
```
细胞壁|支持保护细胞形态|
叶绿体|光合作用场所|物质能量系统
线粒体|有氧呼吸释放能量|物质能量系统
```
`所属系统` 字段留空时只支持方向甲(纯辐射);多条目共享同一系统名时方向乙的图层导览才能分段——同一份数据同时喂给甲乙两个母版,由母版路由决定视觉形态,不是两套数据。位置锚点不要求 LLM 给坐标(历史教训:坐标类字段极易被模型瞎编导致图文错位),沿用 `ObsCalloutMaster` 现有做法——渲染器按条目数量自动分配四周/分层槽位。

**复用**:直接升级 mainline 观察幕母版②引线标注(`ObsCalloutMaster` / `CalloutRow`,`components/mainline/scene-views/visual-slide.tsx`)——现状吃的是通用 `scene.boardText`(单行说明,无结构/功能字段区分),升级点是切到专属 `structureCallouts` 槽(双字段)。方向乙作为该幕型的新母版⑤登记进 `layout-form-registry.ts` 的 `visual-observation` 序列并入气质路由(见 master-routing 气质登记表)。系统 B(`ConceptVisual`/`EducationalVisual`)没有解剖结构类型,不涉及 concept-map/experiment-board 复用。

**优先级**:P0——现状是唯一"部分"起点,升级成本最低(沿用既有母版骨架换数据契约),且结构图解是生物最高频呈现内容。

### 生理流程(血液循环/光合作用等·过程分步)

**教育内核**:过程是有向的、分阶段的,很多生理过程还是**环状**(血液循环、卡尔文循环)而非线性——学生要看清"流向"和"阶段边界",不是背一串阶段名称。

**要超越的教材形态**:方框 + 箭头流程图或简笔环形图,配色灰暗、箭头密集处易读性差,循环结构常被画成"首尾断开的两条线"看不出闭环。

**超越设计·方向甲【环线站台图】**:跨域移植地铁线路图语法(呼应 harvest 素材里"地铁图"的现成参照系)——把生理过程画成一条**环线**(或直线,视过程是否闭环而定):站点 = 器官/结构节点,圆形站徽 + 站名;线路 = 物质/血液流向,双线并行时用双色区分(如动脉线暖红/静脉线冷蓝);每站旁挂一张小卡片写"在这里发生了什么变化"(如"肺:释放 CO₂,结合 O₂")。地铁图的"环线"隐喻天然契合血液循环这类闭合过程,现代、清晰、信息密度可控。

**方向乙【分镜胶片带】**(结构真异质):不用站点网络逻辑,改用 Kurzgesagt 式**横向连续分镜带**——每个阶段是一格"胶片"特写(局部结构 + 一句变化 + 阶段序号),格与格之间用箭头衔接,若过程闭环则末格用一条回绕弧线连回首格(不构成"环状拓扑",是"线性叙事首尾呼应")。这是"时间轴分镜"视角,和甲的"空间网络站点"视角完全不同构——甲让学生看清"发生在哪个结构",乙让学生看清"先后顺序与镜头感",服务不同的记忆锚点。

**学段四档**:低小——分镜带只留 2-3 格,超大插画 icon + 巨大圆润箭头,像绘本翻页,不出现"环"的抽象概念;高小——4-5 站/格,轻游戏化(逐格点亮像闯关,配小徽章);初中——完整环线图或 6-8 格分镜,开始标数据变化(如"O₂浓度"小趋势箭头),编辑设计感;高中——精密多线程(如光合作用光反应/暗反应两条并行线在类囊体膜/基质两站交汇),学术克制,接近专业教学信息图。

**数据结构建议**:`contentSlots.processStages`,每行 `阶段名|发生位置(可选)|变化说明|(仅末行可选)loop`,按流程顺序:
```
右心室|心脏|收缩,推血入肺动脉|
肺部毛细血管|肺|气体交换,血液携氧|
左心房|心脏|接收含氧血|
左心室|心脏|收缩,推血入主动脉|loop
```
末行出现 `loop` 标记时渲染器把首尾相连(环线闭合/分镜回绕弧线);非环状过程(如光合作用的光反应→暗反应)末行留空即为直线呈现。位置字段允许缺省(如"胃"这类单结构过程不需要"位置"层)。

**复用**:现状缺口,无直接同构母版。数据契约上可参照系统 B `experiment-board`(`EducationalVisual.tsx` 的 `ExperimentBoard`,字段为 objects/conditions/observations/conclusion 的四段式)"把过程拆成具名阶段字段"的思路,但**不沿用其正则推断方式**(该组件靠 regex 猜内容,是本库明令淘汰的旧路数,见 `maolab-regex-dispatch-risk`)。视觉骨架上,甲方向"横向站点带"可类比复用 `TimelineEventsView`(`content-forms.tsx`)的横带节点排布技术(时间轴的"年代节点"→生理过程的"阶段节点"),但配色语义、站徽图形、双线并行需要全新设计,不是直接换皮。

**优先级**:P0——生物学科最核心的教学动作之一(循环/呼吸/光合/激素调节皆靠它),当前完全空白,是生物学科"专业感"缺失最刺眼的一块。

### 分类树(分类阶元层级)

**教育内核**:分类是嵌套层级(界门纲目科属种),但真正的学习目标是"划分依据"(为什么这个物种归到这一类),不是背一串阶元名词。

**要超越的教材形态**:缩进列表或简笔树状图,黑白无层次,看不出"依据了什么特征"。

**超越设计·方向甲【年轮辐射树】**:跨域移植数据可视化里的 radial tree / sunburst(基因组学分类图、iTOL 一类系统发育图的现代变体)——中心是最高阶元(界),向外一圈圈辐射到门→纲→目→科→属→种,每一圈是一个阶元层,同心圆本身自带"越分越细"的向心/离心隐喻,选中一条从圆心到边缘的路径高亮成一条辐射带,沿途标注划分依据的关键词。信息密度高、拓扑感强,天然契合"层级细分"的认知模型。

**方向乙【检索护照链】**(结构真异质):不用辐射拓扑,改用**线性判断链**——借鉴二歧分类检索表(dichotomous key)的现代重制 + 图鉴 App(Pokédex/PlantSnap 一类)的护照式卡片:每一级阶元是一张横向卡片,卡片之间用"因为……所以属于……"的判断句连接(如"因为具脊索 → 归入脊索动物门"),卡片右下角挂一个图标化特征徽标(如"恒温""胎生""羽毛"的小 icon)。这是"逐步判断"视角而非"整体拓扑"视角——甲让学生一眼看全"这个物种在分类树的什么位置",乙让学生走一遍"科学家是怎么判断出这个分类的"科学方法过程,教育目标不同,结构天然异质,不是硬造差异。

**学段四档**:低小——护照链只留 2-3 级(不出现严格阶元名,只讲"这是像鸟类的动物吗"这类大类判断),超大萌系 icon,翻页绘本感;高小——4 级卡链,"因为……所以……"判断句上线,图鉴游戏风格;初中——完整七阶元,甲乙皆可给,特征 icon 系统化;高中——完整辐射树含拉丁学名,或严谨检索链,同心圆分区精密、克制无萌系装饰。

**数据结构建议**:`contentSlots.taxonomyLevels`,每行 `阶元名|类群名|判断特征(可选)`,从高到低单一路径:
```
界|动物界|
门|脊索动物门|具脊索
纲|哺乳纲|胎生,哺乳
目|食肉目|
科|犬科|
种|家犬|
```
v1 只支持单一路径(讲透一个具体物种的完整分类链),多分支对比(如"猫 vs 狗在纲以下分叉")留作后续扩展,不在本批强求。

**复用**:系统 B `concept-map`(`ConceptMapBoard`,`EducationalVisual.tsx`)的数据结构——`nodes: {id,label,role}` + `links: {from,to,label}`——是"节点+带标签的边"的现成先例,分类链本质是这套结构退化为单链的特例(每个阶元是一个节点,阶元间的边标签就是判断特征),可直接参照其字段设计,**不沿用其功能性药丸图视觉**(ConceptMapBoard 是蓝色圆角药丸 + 黑色箭头的功能性风格,达不到"设计感"门槛,视觉层按本节方向甲/乙全新做)。

**优先级**:P1——教学重要但呈现频率略低于结构图解/生理流程,过渡期可暂用通用列表卡片。

### 遗传图解(Punnett 方格/遗传图谱·遗传规律)

**教育内核**:两类不同的关系结构服务两类不同的教学目标——等位基因组合的**概率**结构(棋盘交叉,一代内)与家族性状的**谱系传递**结构(多代追溯)。比例(3:1/1:1)和谱系符号必须规范可核验。

**要超越的教材形态**:黑白方格表格 + 圆形方形家系符号图,规范但呆板,比例关系只有数字、没有视觉量感。

**超越设计·方向甲【棋盘卡矩阵】**:保留 Punnett 方格的方阵逻辑(教育正确的核心不能丢——棋盘本身就是这个知识点的标准表达),但材质现代化:行/列表头是配子(如精子 A/a、卵子 A/a),用醒目色块 + 斜体等位基因字母;交叉格是圆角卡片,显示基因型(AA/Aa/aa)+ 对应表现型小插画 icon(如显性圆润豆荚 vs 隐性皱缩豆荚,而非纯文字"圆粒/皱粒");底部配一条比例统计条,3:1 用色块宽度比例可视化而非纯数字。

**方向乙【世代谱系带】**(结构真异质):不用棋盘矩阵,改用**横向世代时间带**——借鉴族谱可视化的现代设计:横向按世代分带(祖代→子代→孙代),每位家庭成员是一个圆形(女)/方形(男)头像 icon(遵循标准遗传学谱系符号规范,教育正确),代际连线上用颜色编码传递的等位基因(显性红色基因条/隐性蓝色基因条附着在连线上),患病者/携带者用填充深浅区分。棋盘服务"单代概率推算",谱系带服务"多代遗传病追溯"——两者本来就是遗传学里两种不同的分析工具,教学目标天然不同,结构异质不是硬造。

**学段四档**:低小——不涉及正式 Punnett 概念(超纲),只做"像不像爸爸妈妈"的具象配对游戏(毛色/花色卡通配对);高小——简化 2×2 棋盘,性状图标化(豌豆花色/花瓣数),游戏配对感强;初中——完整单基因 Punnett 方格 + 比例条,或简版三代谱系带,编辑设计;高中——双因子方格(4×4)+ 严谨统计,或完整多代谱系带含携带者判定,精密学术、零装饰。

**数据结构建议**:两个独立槽,分别服务两个方向(同一幕按教学内容选其一,不强制同时出现):
- `contentSlots.punnettSquare`,首行可选统计提示 `#ratio:3:1`,其后每行 `配子组合|基因型|表现型`:
```
#ratio:3:1
AA|AA|高茎(显性)
Aa|Aa|高茎(显性)
aa|aa|矮茎(隐性)
```
- `contentSlots.pedigreeChart`,每行 `代际|个体编号|性别(M/F)|表现型状态(患病/携带/正常)|父编号,母编号(可选)`:
```
1|F1|F|患病|
1|F2|M|正常|
2|F3|F|携带|F1,F2
```

**复用**:两个槽均无现成 mainline 母版,系统 B 也无对应类型,是纯新增缺口。谱系带方向可类比复用 `TimelineEventsView`(`content-forms.tsx`)的横向代际带排布技术(时间轴的"年代刻度"→谱系的"世代刻度"),但个体符号(圆/方)、连线基因编码、患病填充是全新视觉语言,不是简单换皮。

**优先级**:P1,且两个子方向不等权——棋盘方向(甲)教学高频、实现成本相对低,可提前;谱系带方向(乙)可稍缓,视遗传病专题课的实际出现频率排期。

### 食物链与食物网(能量流)

**教育内核**:能量单向流动、逐级递减(十分之一定律);食物网是多条食物链交织的**网状**结构,不是孤立的一条链——"网"本身就是要教的那个结构,不能简化丢失。

**要超越的教材形态**:简笔动物图 + 单箭头链条,或密集蛛网状连线图挤在一起看不清方向,能量递减关系全靠文字描述,没有视觉量感。

**超越设计·方向甲【能量链标带】**:横向图标链——太阳→生产者→初级消费者→次级消费者→顶级消费者,每个营养级是一枚圆形生物插画徽章,箭头表示能量流方向且**箭头本身逐级收窄变细**(把十分之一定律直接视觉化成"箭头越来越细",而不是另配一段文字解释);侧边或底部配一条能量金字塔色块条,每级色块高度按比例递减对应。单链、清晰,适合初次接触能量流概念。

**方向乙【捕食关系网】**(结构真异质):不用单链+金字塔的线性衰减逻辑,改用跨域移植自数据可视化的 **network 图**——所有物种是圆形节点,按营养级水平分层摆放(生产者一排/初级消费者一排/以此类推),捕食关系用指向捕食者的曲线连接,同层节点间用极淡的引导线暗示同一营养级;可高亮其中一条路径(从生产者到顶级消费者)演示"食物网里的一条食物链"是整张网的一个子路径。这是"网络拓扑"视角而非"线性链"视角,是唯一真正呈现"网"而非"链的集合"的方向,直接对应食物网(区别于食物链)的教学目标。

**学段四档**:低小——食物链 3-4 环具象动物插画 + 大箭头,"谁吃谁"绘本翻页感,不出现能量金字塔抽象概念;高小——5-6 环 + 简化能量金字塔色块条,逐环点亮的轻游戏化;初中——完整食物网节点图(8-12 个物种)+ 营养级分层标注,编辑设计感,开始标注能量流数据;高中——复杂食物网 + 精确能量金字塔数值(生产者 100%→初级 10%→次级 1%),学术图表级精密、零萌系装饰。

**数据结构建议**:
- `contentSlots.foodChain`,每行 `生物名|营养级(可选)|能量说明(可选)`,按能量流动顺序(方向甲直接吃这份数据):
```
水稻|生产者|固定太阳能
稻飞虱|初级消费者|摄食生产者
青蛙|次级消费者|摄食初级消费者
蛇|顶级消费者|摄食次级消费者
```
- `contentSlots.foodWebLinks`(方向乙网络图额外需要,是附加键不替代 foodChain),每行 `捕食者|被捕食者` 表示一条捕食边:
```
青蛙|稻飞虱
蛇|青蛙
鹰|蛇
鹰|青蛙
```

**复用**:方向甲的单链横向带可类比复用 `TimelineEventsView` 的横带节点排布技术(时间轴节点→营养级节点),箭头收窄动效为新增。方向乙的网络图直接复用系统 B `concept-map`(`ConceptMapBoard`)的 `nodes + links{from,to,label}` 数据结构先例——食物网本质是"多对多关系图",和 concept-map 的图结构同构(区别于分类树是这套结构的单链退化特例,食物网是这套结构的满血多对多用法),但视觉层同样不沿用药丸图,按"网络节点分层布局"全新设计。

**优先级**:P2——相对小众,当前可用通用列表/icon 卡片临时过渡,紧迫度低于结构图解、生理流程、遗传图解。

### 反同质自检(creation.md 强制项)

- 五类内容合计给出 10 个方向,两两成对时结构均不同构,不是同一套"卡片+accent+编号"换皮:双层引标(辐射标注)↔系统图层卡(层级切片);环线站台(空间网络)↔分镜胶片带(时间叙事);年轮辐射树(向心拓扑)↔检索护照链(线性判断);棋盘卡矩阵(单代概率)↔世代谱系带(多代追溯);能量链标带(线性衰减)↔捕食关系网(多对多网络)。
- 拒绝"生物学科统一皮肤"陷阱:五类分别移植了地铁图、胶片分镜、radial tree、图鉴护照、族谱时间带、force-directed network 六种跨域语言,没有两类共用同一视觉隐喻。
- 正确性红线自查:引线标注/棋盘/谱系符号(圆女方男)/十分之一定律箭头收窄,均是学科规范的可视化而非自由发挥,不因"设计感"牺牲科学正确性。
- 学段分档不是简单缩放:低小档多类内容明确"不出现"抽象概念(环状拓扑、Punnett 概率、能量金字塔),不是画小一号的高中版。

## 视觉分工标注(位图 / 矢量)

> 依 `2026-07-23-typed-content-forms-spec.md` §0.7 分工铁律 + §0.8 精准度打磨校准。生物是「写实器官/生物体位图 + 矢量引线/流程/结构标注」的典型混合学科——校准样例见 `raster-upgrade-demo.html` 第一屏(眼球写实位图底 + 矢量引线双层 chip),本节把该样例的分工语法套到生物五类内容的每个方向。总原则:**器官/生物体"长什么样"→生成位图;引线/名称/流程方向/遗传比例/分类连线/能量数值"结构或数值精确"→矢量**。位图内一律不烘焙任何文字(名称/数值/箭头全部留给矢量层叠加),幕面白为主,位图只收在图卡/局部区域内,不整幅出血。

### 结构图解(引线标注)

**位图部分**:结构主体本身——半写实器官/组织剖面(如眼球、心脏、叶片横切、细胞整体轮廓),near-white 或中性浅背景,无任何文字或箭头烘焙进图。方向甲(双层引标)只需一张居中结构位图;方向乙(系统图层卡)额外需要同一结构在"整体剪影"构图下的位图(供系统色带联动高亮时,高亮态可用同一张位图的色叠加蒙版,不需要重新生图)。保真档:低小/高小走 **stylized-teaching**(圆润、亲和、略卡通化但结构不失真);初中/高中走 **diagram-accurate**(专业解剖图级写实,呼应"权威图鉴"精度要求)。

**矢量部分**:方向甲——引线(贝塞尔曲线,绕开结构主体,终点精确落在结构位置)+ 终端双区块 chip(上区结构名/下区功能一句话);方向乙——系统色带(横向分段色块,HTML/CSS)+ 联动高亮蒙版的描边轮廓 + 色带下方浮现的结构-功能卡组。两类都完全由 `structureCallouts` 数据驱动,不含位图坐标(位图不承担定位职责,定位精度全部在矢量层)。

**白为主**:图卡占幕面局部(通常居中或偏一侧),背景色与位图边缘融合为浅色调,chip/色带均为白底或近白底浮层,幕面其余留白。

---

### 生理流程(血液循环/光合作用等)

**位图部分**:方向甲(环线站台图)——每个"站点"的站徽是一枚小型写实/风格化生物插画(如心脏、肺、叶绿体的局部特写),圆形裁切,近白底,stylized-teaching 为主(即便高中也不需要过度写实,站徽是"标识"而非"教学主图");方向乙(分镜胶片带)——每一格"胶片"是对应阶段的局部结构写实特写(如光反应格里的类囊体膜、暗反应格里的基质),diagram-accurate(初高中)或 stylized-teaching(低小高小),同样无烘焙文字。

**矢量部分**:方向甲——线路本身(SVG 路径,双色区分动脉线/静脉线或光反应/暗反应两条并行线)+ 站名标签 + 环线闭合弧线 + 数据趋势小箭头(如"O₂浓度↑");方向乙——格间衔接箭头 + 阶段序号 + 回绕弧线(loop 标记时)+ 每格下方的变化说明文字条。位置字段(发生位置)、阶段顺序、loop 判定均由 `processStages` 数据驱动矢量骨架,位图只填充站徽/胶片格内容,不参与流程拓扑本身。

**白为主**:环线/胶片带整体铺陈在白底画布上,站徽/胶片格是仅有的"图"区域,线路、箭头、文字条均为矢量色块或细线,不产生大面积深色位图出血。

---

### 分类树(分类阶元层级)

**位图部分**:方向甲(年轮辐射树)——每个末端叶节点(通常是"种"或代表物种)配一枚小型写实/风格化生物插画图标,近白底,尺寸随环层向外递减;方向乙(检索护照链)——每张卡片右侧配一枚该类群代表物种的写实缩略插画(护照/图鉴 App 语法,类似证件照裁切)。两方向的位图都只是"点缀级"而非主体——分类树本质是结构关系图,主体是矢量。保真档:低小高小 stylized-teaching(萌系图鉴感);初高中 diagram-accurate(接近科学图鉴插画)。

**矢量部分**:方向甲——同心圆分层线 + 辐射分割线 + 选中路径高亮带 + 沿途划分依据关键词标签;方向乙——卡片间"因为……所以……"判断句连接线 + 特征徽标(图标化,矢量绘制而非生图)+ 阶元名称/拉丁学名文字层。分类阶元的层级结构、路径高亮、判断链顺序完全由 `taxonomyLevels` 数据驱动,是纯拓扑关系,不依赖任何位图定位。

**白为主**:辐射树/护照链均以白底为画布主体,位图缩略图仅占节点/卡片内一小块面积(圆形或圆角裁切),整体页面留白充分,不出现位图撑满构图的情况。

---

### 遗传图解(Punnett 方格/遗传图谱)

**位图部分**:方向甲(棋盘卡矩阵)——交叉格内的表现型图标(如显性圆润豆荚 vs 隐性皱缩豆荚、显性圆粒 vs 隐性皱粒),小尺寸风格化插画,near-white 底,stylized-teaching(全学段皆可用统一亲和度,遗传图解不需要"写实到吓人"的档位);方向乙(世代谱系带)——通常**不需要位图**,个体符号(圆/方)本身就是学科规范矢量符号,若要点缀可给患病/携带表现型配极小图标,非必需。

**矢量部分**:方向甲——棋盘方格线(精确 2×2 或 4×4 网格)+ 配子表头色块 + 基因型字母标注(斜体规范)+ 底部比例统计色块条(3:1 等,色块宽度按比例精确绘制);方向乙——世代分带横线 + 圆/方个体符号(学科规范谱系符号,矢量绘制,必须精确不能用位图"画像素级不准的示意")+ 代际连线 + 连线上的等位基因颜色编码 + 填充深浅表示患病/携带状态。比例数字、基因型组合、谱系拓扑均是必须精确核验的内容,一律矢量,不进位图。

**白为主**:棋盘/谱系带整体是浅色网格与线条,位图(若用)只作为交叉格内小图标点缀,整体高亮度、留白充分,符合"精密学术、零装饰"的高学段气质。

---

### 食物链与食物网(能量流)

**位图部分**:每个营养级/物种节点是一枚圆形生物插画徽章(方向甲能量链标带、方向乙捕食关系网共用同一套物种插画资产),near-white 底裁切,stylized-teaching 为主(低小高小更卡通化,初高中略写实但仍是"徽章"体量,不追求解剖级精度——物种识别度比写实度更重要)。

**矢量部分**:方向甲——横向箭头链(箭头本身逐级收窄变细,精确对应十分之一定律的视觉隐喻)+ 底部能量金字塔色块条(色块高度按比例精确递减);方向乙——network 连线(捕食关系曲线,指向捕食者)+ 营养级分层引导线(极淡横线暗示同层)+ 高亮路径描边(演示"网中一条食物链")+ 能量数值标注(如"100%→10%→1%")。能量递减比例、连线方向、分层结构都是数值/拓扑精确内容,一律矢量绘制,位图徽章只负责"这是什么生物"的识别功能。

**白为主**:徽章圆形裁切散布在白底画布上,箭头/连线/金字塔色块均为矢量图形,不产生位图大面积覆盖,整体保持信息图级的明快留白。

---

### 分工小结(生物学科的位图/矢量配比特征)

生物五类内容里,**结构图解、生理流程**偏"位图承重"(结构/器官"长什么样"是教学重点之一,呼应眼球校准样例的档位);**分类树、遗传图解、食物网**偏"矢量承重、位图点缀"(这三类的教学核心是关系拓扑/概率/数值,位图只做小尺寸物种识别图标,不需要写实质感撑场面)。这与 §0.7 判据一致:结构图解的"结构长什么样"重要→位图挑大梁;分类树的"归属关系对不对"重要→矢量挑大梁。全学科统一执行"位图无烘焙文字、矢量层承载全部文字与数值、白为主约束幕面而非位图内容本身"三条铁律。
