## 语文

> 古诗词已单独完成三方向(境/律/叙——竖排衬线夜色氛围的意境沉浸、拼音平仄声律信息图的声律解剖、一句一卡线描意象的逐句叙事流),不在本节重复展开,仅作为本节的野心标杆。本节覆盖语文剩余八类专属内容:文言文、现代文精读、拼音、汉字、成语与词语、对联、修辞手法、病句与标点修改。全部遵循 0.2 五条地基(白为主 / 图辅文主 / 正确性可核验 / 分学段四轴 / 反同质 ≥2 结构真异质方向),数据槽位遵循 0.6 的系统 A 显式槽键铁律——`contentSlots` 是 `Record<string,string>`,每类新增槽位延续 `poemLines`/`timelineEvents`/`dialogueScript` 的"单一具名槽 + 纯函数 parser + 行内分隔符"约定,渲染端只认键、不做正则猜测。

### 文言文

- **教育内核**:建立文言→现代汉语的映射能力——断句语感、虚词功能、实词古今义、词类活用,不是逐字翻译背诵。
- **要超越的教材形态**:左右双栏对照(原文/译文)+ 页脚编号注释,黑白铅字,原文与译文之间没有可交互的层次。
- **超越设计 · 方向甲【叠层批注 Interlinear Layer】**:借鉴代码编辑器的 hover 注释与语言学教材的逐词行间对照(interlinear gloss)。原文大字衬线置顶层,句读处以细竖线标出断句(非顿号);点击/长按字词,原字下方弹出小卡(释义 + 词性色块,如"使动用法"用高饱和小色块提示);译文整行以小字浅灰浮现于原文正下方,构成"原文-释义-译文"三层堆叠而非左右分栏。虚词(之乎者也)单独描边高亮,建立文言功能词的视觉词类意识。为什么现代:像 Kindle 生词查询、沉浸式阅读器的对照模式,是学生已经在用的交互隐喻,不是教材脚注。
- **超越设计 · 方向乙【卷轴旅程 Scroll Journey】**:不做静态对照,把整篇文言文变成一条可横向翻页的连续长卷(呼应手卷这一书画载体,但用现代排版)。原文以稀疏大字沿卷铺开,重要断句处插入"节点"(类似地铁站点圆点);点开节点展开该句译文 + 一张极简线描场景小图(如"其一犬坐于前"配一只蹲坐的线描犬)。是叙事推进 + 空间移动的体验,与方向甲的"层叠对照"在结构上完全异质。为什么现代:借用游戏关卡地图/剧情进度条的视觉语言,把读一篇古文变成"通关一段旅程"。
- **学段四档**:低小——蒙学短句(如三字经)走方向乙,插图主导,节点稀疏;高小——简短文言小故事以方向乙为主,断句提示弱化为韵律拍点;初中——方向甲为主力,虚词/实词/词类活用系统上线,断句判断标注为考点;高中——方向甲深化,浮层卡含通假字/古今异义/特殊句式多维标签,插图装饰全部撤除,趋近古籍数字化平台的克制排版。
- **数据结构建议**:`contentSlots.classicalText`(原文,按句换行,含标点断句);`classicalGloss`("词|释义|语法标签(可选,如'使动用法')" 每行一条);`classicalTranslation`(逐句白话译文,行序与 `classicalText` 一一对应)。三槽同级触发,与 `poemLines` 平级判断。
- **复用**:系统 B 无直接适配渲染器;数据模型上可参考 `dialogueScript` 的"多行对齐 + 分轨"解析思路(原文行与译文行的对位关系),渲染层需全新设计。
- **优先级**:高(初高中文言文是绝对高频刚需,当前 [缺口] 与实际教学落差最大)。

### 现代文精读

- **教育内核**:结构化地读——识别段落功能(总起/论证/转折/总结)与证据链,而不是逐字翻译。
- **要超越的教材形态**:段落旁印刷体眉批("第一段:开门见山"),字小、居页边,学生基本不看。
- **超越设计 · 方向甲【编辑手写批注层 Editorial Marginalia】**:借鉴杂志编辑校对稿与 Medium/Notion 的高亮划线 + 批注气泡。正文左对齐主栏,右侧留白栏放批注气泡,批注用手写风字体 + 彩色下划线以 SVG 连接线连回正文对应句子;不同批注类型用不同前缀符号("?"疑问 / "→"逻辑关系 / "★"主旨句)。为什么现代:是学生数字阅读(高亮 + 评论气泡)的日常体验,不是泛黄纸页做旧的仿古批注。
- **超越设计 · 方向乙【文脉热力条 Structural Rhythm Bar】**:不做旁注,在正文左侧加一条纵向"文脉条"(类比音频波形/心电图),按段落分块染色,颜色映射段落功能(叙述/议论/抒情/说明各一套语义色),块宽映射段落长度;点击色块平滑滚动定位对应段落。学生先读"文章心电图"整体把握结构,再入正文细读——与方向甲"逐句批注"的细读路径在认知起点上完全相反(先俯瞰 vs 先精读)。为什么现代:像音乐 App 播放进度波形图、代码编辑器 minimap 缩略导航,把隐藏的文脉变成一眼可读的空间结构。
- **学段四档**:低小——几乎不做精读训练,如需要则用方向乙简化版,只分"开头/中间/结尾"三色块配大图标;高小——方向乙为主,功能分类扩到 4-5 种,引入"过渡句"概念;初中——方向甲上线,批注类型标准化为"论点/论据/论证方法",两方向可共存(文脉条导航 + 批注层细读);高中——方向甲深化为议论文/文学类两套批注词表,强调作者意图与写作手法,文脉条弱化为极简侧边缩略条不再喧宾夺主。
- **数据结构建议**:`contentSlots.passageParagraphs`(原文分段,每段一行);`passageAnnotations`("段落序号|批注类型|批注文字" 每行一条,类型如 论点/论据/转折/主旨);`paragraphFunction`(每段一个功能标签,专供文脉条颜色映射,生成期显式产出,不由 annotations 推断——遵守禁正则猜测铁律)。
- **复用**:文脉条"分段染色 + 等宽块 + 点击定位"的结构可类比 `timelineEvents` 的位置映射渲染逻辑,渲染层重做但数据模型思路相通。
- **优先级**:高(现代文阅读理解是语文教学第一大板块,现状彻底空白)。

### 拼音

- **教育内核**:音形对应 + 四声调值升降(阴平/阳平/上/去)的实际听感。
- **要超越的教材形态**:田字格 + 声调符号印在字母上方,扁平黑白,抽象符号对低龄学生偏晦涩。
- **超越设计 · 方向甲【调值曲线 Tone Contour】**:把四声画成真实音高曲线(类比音频编辑软件的 pitch curve、地铁报站提示音的音高动画)。声母(浅蓝卡)与韵母(浅橙卡)靠拢"咬合"成一个音节(拼图隐喻),声调曲线悬浮在音节上方(一声高平线/二声上扬线/三声先降后扬/四声陡降线),播放音频时曲线同步描边动画。为什么现代:像多邻国的发音可视化、K 歌 App 的音高对比条,把抽象调值变成看得见的运动轨迹。
- **超越设计 · 方向乙【口型剖面卡 Mouth Shape Card】**:不做音高曲线,做发音部位口型剖面(参照语音学口腔矢状面图,简化为友好插画,非医学解剖图)。每个韵母配一张"嘴型"图标(圆口/扁口,复韵母用滑动渐变小动图),声母配简笔人脸侧影 + 发力部位亮点(舌尖/舌根/唇齿)。这是从"听觉"转向"发音动作"的完全不同认知路径,与方向甲结构真异质。为什么现代:像语言学习 App 的口型教学动画,把"怎么读"变成具身可模仿的动作指导,契合低龄学生的模仿学习方式。
- **学段四档**:低小——拼音教学主战场,两方向均以大插画 + 单音节一屏为主,口型卡尤适合跟读模仿;高小——调值曲线用于"声调竞猜"轻游戏化练习,服务多音字辨析;初中——拼音降为工具,仅生僻字/文言文场景走极简小标注;高中——几乎不独立出现,仅诗词平仄场景复用调值曲线的极简变体。
- **数据结构建议**:`contentSlots.pinyinSyllables`("声母|韵母|声调(1-4)|例字" 每行一个音节);`pinyinToneFocus`(可选,标注本幕聚焦声调,用于练习模式)。
- **复用**:与古诗"律"方向的平仄声律信息图共享同一套 tone-contour 视觉基元(渲染参数不同,可复用底层曲线绘制逻辑)。
- **优先级**:高(低小刚需,现状完全空白,且实现性价比高、易出"眼前一亮"效果)。

### 汉字(笔顺/结构/部首/造字理据)

- **教育内核**:汉字不是任意符号——结构可拆解(独体/合体)、部首表意、六书造字有历史理据。
- **要超越的教材形态**:田字格 + 编号箭头笔顺图,静态枯燥,造字理据顶多一句"象形字"文字说明,不呈现。
- **超越设计 · 方向甲【笔顺编舞 Stroke Choreography】**:借鉴书法字帖 App 与运动轨迹图。汉字先以极淡灰骨架呈现结构框(上下/左右/包围结构分割线示意),笔画按笔顺逐笔描边动画(SVG path 逐笔绘制 + 序号小圆点),完成后叠加部首高亮色块 + 部首含义小标签("氵=水"配一滴水线描图标)。为什么现代:像字体设计软件的路径动画、运动教学的动作分解慢镜头,把临摹变成可交互分步演示。
- **超越设计 · 方向乙【造字理据卡 Etymology Card】**:完全不处理笔顺,聚焦"这个字为什么长这样"——甲骨文/金文简化线描图形(提炼图标化,非考古复原插画)并排现代楷体,中间一条时间轴压缩为 3-4 个字形节点(甲骨文→小篆→楷书),配一句白话造字故事("'休'=人靠在树旁休息")。这是历史纵深的叙事结构,与方向甲"当下书写动作"的结构完全异质。为什么现代:像博物馆数字展牌、"汉字冷知识"类科普短视频封面的教育正确版,满足文字考古式好奇心。
- **学段四档**:低小——方向甲为主,大字 + 慢速逐笔动画 + "跟写打星"游戏化反馈;高小——方向甲与方向乙轻量结合,引入部首归类"部首家族墙",造字理据以象形字故事化讲述为主;初中——方向乙上线为主力,六书完整引入(象形/指事/会意/形声),形声字用双色区分形旁表意与声旁表音;高中——方向乙深化为文字学视角(通假字/异体字字形辨析),笔顺动效基本退场,趋近文字学工具书的现代数字版。
- **数据结构建议**:`contentSlots.characterStrokes`(本字 + 笔画数,或"笔画序号|笔画名称" 每行一条);`characterRadical`(部首 + 部首释义);`characterEtymology`("字形阶段(甲骨文/金文/小篆/楷书)|说明" 每行一条,驱动演变箭头)。
- **复用**:部首归类可借鉴 concept-map 的分组聚类数据思路(视觉全新设计);笔顺动效无现成复用,需专属 SVG 渲染器。
- **优先级**:中高(低小刚需高频,但笔顺动效实现成本较高;建议先做造字理据卡这条更轻的线,再补笔顺动效)。

### 成语与词语(释义·源流·用例·近反义)

- **教育内核**:词语是语义网络节点——有出处(源流)、有语义邻居(近反义)、有使用语境(例句),不是孤立释义条目。
- **要超越的教材形态**:词条式罗列(词 + 拼音 + 释义 + 一个例句),像字典页,零关联感。
- **超越设计 · 方向甲【语义星系 Semantic Constellation】**:借鉴同义词思维导图与知识图谱可视化(如 Obsidian 关系图谱)。目标成语居中作恒星节点(大字卡片),近义词/反义词作卫星节点环绕(近义词暖色连线靠近、反义词冷色连线在对侧);点击卫星词可切换为新中心("词语漫游"体验);源流故事作背后可展开的故事卡(极简插画 + 一句话典故),例句以底部字幕形式滚动出现。为什么现代:像知识图谱工具与音乐 App"相关歌曲"推荐环,把词汇学习变成可探索网络而非线性背诵列表。
- **超越设计 · 方向乙【成语剧场卡 Idiom Scene Card】**:不做语义网络,做典故场景重现——把成语出处浓缩成一张漫画分镜式场景插画(如"刻舟求剑"画简笔人物在船舷刻记号,船在动水在流的动态箭头暗示荒谬感),释义以海报"标语"叠加画面上方,例句作"台词气泡"从人物嘴里冒出。这是叙事具象化结构,与方向甲的抽象网络结构完全异质。为什么现代:像历史科普短视频封面、独立游戏过场画面,让"望文生义"式误解在具象场景中被当场纠正。
- **学段四档**:低小——方向乙为主,场景插画大而简单,聚焦"字面意思 vs 实际含义"的反差趣味,不涉及语义网络;高小——方向乙继续,叠加简单"近义词朋友圈"小标签建立语义关联意识;初中——方向甲上线为主力,语义网络扩大到 4-6 个关联词,源流故事文字量增加;高中——方向甲深化,节点加入感情色彩/语体色彩(褒贬/书面口语)维度分层,排版转向工具书质感。
- **数据结构建议**:`contentSlots.idiomHeadword`(成语 + 拼音 + 核心释义);`idiomOrigin`(源流故事白话文本);`idiomRelations`("关系类型(近义/反义)|词语|简释" 每行一条);`idiomExamples`(例句,每行一条)。
- **复用**:语义星系网络可直接复用 concept-map(C03 关系结构)的节点-连线数据模型,视觉需按本节重做(去功能化外观,加暖冷连线语义色 + 悬浮交互意图)。
- **优先级**:中(高频但非最紧迫;现状用通用文字卡可勉强承载,提升空间大但非阻断性缺口)。

### 对联

- **教育内核**:上下联字数相等、词性相对、平仄相反(尤重句脚二四六分明),横批点题。
- **要超越的教材形态**:竖排双行印刷,顶多红黑标出平仄,几乎不讲"对仗"这层结构对应关系。
- **超越设计 · 方向甲【镜像对齐轨道 Mirror Alignment Track】**:借鉴数据表格逐列对齐与 Git diff 并排对比视图。上联下联做成左右两条平行轨道,逐字对齐成列,列间细连接线标注词性对应关系(名词对名词一色、动词对动词另一色);平仄用行内小圆点(○平●仄)贴在每字下方,句脚字平仄点放大高亮强调"仄起平收";横批悬浮两联顶部作"标题拱门"。为什么现代:像 Git diff 并排对比、表格数据逐列高亮,把"对仗"这一抽象语法关系变成看得见的一一映射连线。
- **超越设计 · 方向乙【对称门楼 Symmetric Portal】**:不做逐字对齐分析,把整副对联做成门楼/匾额的现代扁平化图形隐喻——横批作顶部匾额横条,上下联分列左右两根"柱子"(竖排大字,书法感现代衬线);柱身以对称留白与描边呼应建筑对称性,不强调逐字对应而是整体一眼的对称美感直觉先行;平仄仅在句脚点缀,词性关系收进右下角可展开小面板。这是"整体美感直觉"与方向甲"逐字结构分析"的完全不同认知路径。为什么现代:像建筑摄影海报、极简 Logo 的对称构图美学,先建立对联作为"视觉艺术品"的直觉,再引导进入语法分析。
- **学段四档**:低小——基本不涉及创作规则,如遇春联民俗内容走方向乙门楼隐喻,重氛围轻语法,红色只作为灯笼等物件点缀(不做满版红地,遵守白底地基);高小——方向乙为主,引入"横批点题"与"字数相等/意思相关"直觉,不讲平仄术语;初中——方向甲上线,词性对仗 + 基础平仄("马蹄韵"概念)系统讲解;高中——方向甲深化到"一三五不论二四六分明"格律细节,连线增加"工对/宽对"分级标注。
- **数据结构建议**:`contentSlots.coupletTop` / `coupletBottom`(上联/下联整行文字);`coupletTones`(对应每字平仄的序列字符串,上下联各一条);`coupletHorizontal`(横批文字)。
- **复用**:逐字对齐连线的数据结构可类比 `dialogueScript` 的"发言人 + 台词 + 声道"双轨对齐思路,渲染层全新。
- **优先级**:中低(出现频次低于文言文/成语,属于民俗单元的锦上添花,但展示价值高)。

### 修辞手法(比喻/拟人等机制)

- **教育内核**:理解本体-喻体/拟体之间通过什么相似点、什么手法被联结的认知机制,而非死记术语名字。
- **要超越的教材形态**:"本体+喻体+比喻词"三栏填空表格,机械,不揭示"为什么这样比"的思维过程。
- **超越设计 · 方向甲【映射光路图 Mapping Diagram】**:借鉴信息设计的过程箭头图与电路连线图。本体、喻体分列两侧(各配一个线描图标而非纯文字),中间连接线明确标注"相似点"文字(如"弯");连接线形态呼应修辞类型——比喻用实线箭头,拟人用波浪线连向本体并给本体加眼睛嘴巴的拟人化描边,排比用三条平行等长线强调节奏重复,夸张用从小到大发散的三角箭头。为什么现代:像流程图/电路图的功能性连线语言,把每种修辞变成可识别的图形符号系统,靠图形而非术语区分比喻与拟人。
- **超越设计 · 方向乙【修辞显微镜 Rhetoric Zoom】**:不做符号化连线图,在真实例句上做局部放大聚焦——整句平铺呈现,触发修辞的关键词组用圆形取景框(类比地图 App 定位放大/显微镜切片)聚焦放大,框内手绘感批注圈出本体/喻体并写出解读("这里把瀑布比作白练,取的是又长又白这个相似点");多个例句左右滑动切换,像刷图文卡片。这是沉浸真实语境逐句显微分析,与方向甲"抽离出图形符号"的路径认知起点完全相反(具象放大 vs 抽象符号化)。为什么现代:像图片文字批注功能、显微镜科普内容的放大镜交互,让修辞分析像探案找线索一样有解谜乐趣。
- **学段四档**:低小——方向乙为主,例句极简,聚焦"这句话把什么比作什么",一次只讲一种修辞,不用术语连线;高小——方向乙继续,方向甲图形符号开始渗透(如拟人波浪线简化版),建立"修辞有自己的图形长相"意识;初中——方向甲上线为主力,类型扩展到排比/夸张/设问/反问/反复,符号系统标准化;高中——方向甲深化,加入表达效果分析维度(语体/情感强化程度分级),常与现代文精读的批注层联动使用。
- **数据结构建议**:`contentSlots.rhetoricExample`(例句原文);`rhetoricMapping`("修辞类型|本体|喻体或拟体|相似点或效果说明" 每行一条,支持一句多修辞多行);`rhetoricFocusSpan`(可选,需放大聚焦的关键词片段,供方向乙取景框定位)。
- **复用**:修辞图形符号系统可参考 concept-map 的"关系类型→连线样式"映射底层逻辑(关系类型驱动视觉编码),符号词汇需专为语文修辞设计,非直接复用。
- **优先级**:中高(阅读理解与写作高频考点,现状空白,设计切入点清晰、实现相对可控)。

### 病句与标点修改(错误定位·修正)

- **教育内核**:诊断-修复闭环能力——定位错误类型(成分残缺/搭配不当/语序不当/重复赘余/逻辑矛盾等)并给出修正方案,标点同理。
- **要超越的教材形态**:"原句(病句)→ 修改后句子"上下对照,顶多括号插入说明,像批改作业的红笔痕迹,单一无层次。
- **超越设计 · 方向甲【语法诊断面板 Syntax Diagnostics Panel】**:借鉴代码编辑器 linter/IDE 报错提示。原句正常呈现,错误片段加红色波浪下划线(悬浮病句类型图标标签,如"搭配不当"配交叉图标);旁侧或悬浮弹出诊断卡说明错误原因,下方并排展示修正后版本,改动处用绿色高亮标出(diff 风格:删除线 + 新增底色),形成"报错→原因→修复"完整闭环。为什么现代:像 VS Code 错误提示、Grammarly 语法检查界面,是学生写作业时已见过的真实工具语言,天然带专业检查工具的信任感。
- **超越设计 · 方向乙【病句法庭卡 Sentence Courtroom Card】**:不做工具化 linter 观感,把每个病句变成"案件卡"——原句作"案发现场"陈述,病句类型作拟人化"罪名"标签("搭配不当案"配诙谐线描小图标),给出"证据"(具体指出哪个词和哪个词打架)与"判决"(修正方案),多个练习像"案件档案柜"左右翻页浏览。这是游戏化叙事包装(破案)而非方向甲的专业工具包装(debug),认知框架完全不同——一个"你是程序员在 debug",一个"你是侦探在破案"。为什么现代:像推理解谜小游戏的案件卡 UI,把改病句从枯燥批改变成有代入感的小任务。
- **学段四档**:低小——病句诊断极少出现,如有走方向乙极简版,类型仅"话没说完/说重复了"两三种最基础错误,图标化为主;高小——方向乙继续,类型扩展到 4-5 类,出现"你来当小法官"式互动措辞;初中——方向甲上线为主力,病句类型对齐考纲六大类(成分残缺/搭配不当/语序不当/句式杂糅/重复赘余/逻辑矛盾),标点修改并入同一诊断面板;高中——方向甲深化,增加逻辑严密性/歧义句等更高阶诊断维度,去掉图标装饰趋近真实语法检查工具的专业感。
- **数据结构建议**:`contentSlots.faultySentence`(原病句);`sentenceDiagnosis`("错误类型|错误片段|错误原因" 每行一条,支持一句多处错误);`sentenceCorrection`(修正后句子,改动片段用「【】」包裹供渲染器识别增删高亮);`punctuationFocus`(可选,标点专项时标注具体符号位置与正确用法)。
- **复用**:diff 高亮/错误定位视觉逻辑目前 mainline 无现成 UI 组件,需新建;"位置定位+类型标签+修正"三元组的信息分区节奏可参考 experiment-board 的"步骤-现象-结论"三段式,借鉴信息架构节奏而非渲染代码。
- **优先级**:高(初中高频考点 + 写作互评刚需,现状空白,linter 隐喻切入点清晰,实现性价比高)。

## 视觉分工标注(位图 / 矢量)

> 依据总纲 0.7(位图 vs 矢量分工铁律)+ 0.8(精准度)逐类标注。判据:场景/意境/器官等"具象事物、越真越好"→生成位图(接 `imageFidelity` 三档);字形笔顺/拼音调值/平仄/句法成分/批注定位等"结构数值、必须精确"→矢量叠加。语文本节多为「字/词/句 + 结构分析」,场景与意境类偏少,故本节 8 类中纯矢量或近纯矢量占多数,仅文言文卷轴叙事、拼音口型、成语典故、修辞本体喻体等少数子方向含位图。

### 文言文
- **位图部分**:仅方向乙【卷轴旅程】的节点展开小图——文言场景的具象瞬间复现(如"其一犬坐于前"的蹲坐犬)。画风 stylized-teaching(风格化教学插画,非考古写实),仅低小/高小蒙学故事启用;初中起插图装饰全部撤除。Prompt 方向:画面主体是场景中的具体动作瞬间,风格化简笔插画质感,near-white 或浅米底,图内不出现任何文字。
- **矢量部分**:方向甲——断句竖线、虚词描边高亮色块、字词释义弹出小卡、译文浅灰浮现层;方向乙——地铁式站点圆点、进度轨道线。
- **白为主**:纯白为主,节点插画收在展开小卡内,不整幅铺开。

### 现代文精读
- **位图部分**:无。教育内核是文脉结构与批注逻辑,不涉具象场景或意境,方向甲乙均为纯信息设计。
- **矢量部分**:高亮下划线、批注气泡↔正文的 SVG 连接线、批注类型前缀符号、文脉热力条色块(按段落功能着色 + 块宽映射段长)、点击定位交互层。
- **白为主**:纯白,零位图,零深色氛围。

### 拼音
- **位图部分**:仅方向乙【口型剖面卡】的口型/侧脸插画——具象器官类(嘴型/侧脸发力部位)。画风 stylized-teaching(友好圆润风格化,非医学解剖写实),契合低龄具身模仿。Prompt 方向:圆口/扁口口型特写或儿童侧脸剪影,标示唇齿舌位置的风格化插画,色彩明快,近白底,图内不含文字标签。
- **矢量部分**:方向甲——声母浅蓝卡/韵母浅橙卡色块本体、四声音高曲线描边动画、音节咬合拼图边框;方向乙——舌尖/舌根/唇齿发力部位亮点与引线(叠加在口型位图之上)。
- **白为主**:纯白,口型插画收在小图标/小卡范围内,不做整幅氛围图。

### 汉字(笔顺/结构/部首/造字理据)
- **位图部分**:仅造字理据卡的故事化辅助插画(可选增强项),如"休"字造字故事配人靠树休息的风格化小插画,画风 stylized-teaching,仅承载"想看"的故事感,不承载精确信息。字形本体(甲骨文/金文/小篆/楷书图标)不走位图,见矢量部分。
- **矢量部分**:方向甲——骨架结构框线、笔画 SVG 逐笔描边路径、笔顺序号圆点;方向乙——甲骨文/金文/小篆图标本体(须精确复刻历史字形,禁止用生成位图自由发挥导致字形出错)、字形演变时间轴箭头、部首高亮色块与释义标签。
- **白为主**:纯白,故事插画(如启用)收在小卡内。

### 成语与词语
- **位图部分**:方向甲【源流故事展开卡】的典故场景插画(极简瞬间,如"守株待兔"兔子撞树桩)与方向乙【成语剧场卡】的漫画分镜场景插画(核心位图,如"刻舟求剑"人物刻记号+船在动水在流)。画风均 stylized-teaching(方向乙可偏漫画分镜感,低小更卡通夸张)。
- **矢量部分**:方向甲的语义星系节点-连线图(恒星词卡+卫星词卡+暖冷连线+连线粗细/色彩语义编码);方向乙的释义"标语"叠加条、台词气泡外框与指向尾巴。
- **白为主**:纯白幕面,典故场景位图收在故事卡/剧场卡卡片内,不出血占满整幅。

### 对联
- **位图部分**:仅低小方向乙【对称门楼】的民俗氛围点缀(灯笼、门楼木质纹理等小物件),画风 stylized-teaching 或 atmosphere(如需过年气氛可带暖色/深色调,但须收在点缀区内,不做满版红地);初中以上两方向均不需要位图。
- **矢量部分**:方向甲——逐字对齐列、词性对应连线(色彩编码)、平仄圆点(○平●仄)、句脚放大高亮;方向乙——门楼/匾额几何图形本体(横批条+对称柱身留白与描边,纯 HTML/SVG 几何构成,非插画)。
- **白为主**:纯白为主,仅低小民俗点缀允许小面积氛围位图收在卡内。

### 修辞手法
- **位图部分**:方向甲【映射光路图】本体/喻体图标,由原线描图标升级为生成位图小插图(如"瀑布""白练"等具象主体),画风 stylized-teaching(图鉴风格化,非扁平线描);方向乙【修辞显微镜】取景框内可选配对应意象的风格化小插画增强代入感(可选项,例句本身仍以文字为主)。
- **矢量部分**:方向甲——连接线本体(实线箭头/波浪线/平行线/发散三角箭头按修辞类型编码)、相似点文字标注、拟人化描边层(给本体图标加眼睛嘴巴);方向乙——圆形取景框放大机制、手绘感批注圈与解读连线。
- **白为主**:纯白为主,本体喻体位图收在小图标格内(近方形小卡尺寸),不做整幅意境图。

### 病句与标点修改
- **位图部分**:无。方向甲【语法诊断面板】与方向乙【病句法庭卡】均不涉具象场景或氛围;方向乙拟人化"罪名"图标也应以矢量/HTML 简笔图标实现,诙谐感靠措辞与色彩,不需要写实插画。
- **矢量部分**:红色波浪下划线、诊断卡悬浮气泡、diff 风格删除线/新增底色高亮、病句法庭卡的图标标签(矢量绘制)、证据/判决分区排版。
- **白为主**:纯白,零位图。
