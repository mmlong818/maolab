特殊内容呈现 · 设计校准

古诗,不该只是竖排的黑字。
三种超越教材的现代呈现。

同一首《静夜思》,三个结构真异质的方向 —— 沉浸的意境、可视化的声律、逐句的叙述。目的不是还原课本,是让学生想看。请据此校准「设计感」的档位。

01 / 三个异质方向

境 · 律 · 叙

白为主地色不变,颜色只在物件层。每个方向一套专属视觉语法,而非同一张卡片套皮。

静夜思 · 李白
床前明月光疑是地上霜举头望明月低头思故乡
霜色的月光落在床前,他抬头、又低头 —— 一场关于故乡的静默。
李白
方向 A · 境

意境沉浸

竖排现代衬线 + 氛围光渐变 + 一枚现代印章。像一张电影海报/冥想 App,情绪先行。适合诵读、情感体会。

意象 · 明月意象 · 霜情 · 思乡
方向 B · 律

声律解剖

拼音注音 + 平仄节拍带(○平●仄)+ 韵脚高亮(霜/乡)+ 意象标签。把诗的「音乐」做成信息图。适合精读、格律教学。

逐句展开 · 一句一景
1
床前明月光
月光洒在床前
2
疑是地上霜
还以为是霜
3
举头望明月
抬头看月亮
4
低头思故乡
低头想家乡
方向 C · 叙

逐句卡片流

每句一卡:原句 + 白话 + 线描意象图标,可滑动、有进度点。认知负荷最低,像学习 App。适合低龄、初读。

02 / 同一首诗,四种说话方式

按学年分档

分档不是改字号,是改「说话方式」—— 脚手架、密度、抽象度、气质四轴同时移动。

低小 1–2

一幅画 + 几个字

月yuè
  • 方向 C 玩心版:大插画
  • 全程拼音注音
  • 一屏一句,可点读
高小 3–6

逐句 + 意象图

床前明月光
  • 方向 C→B 过渡
  • 去拼音,留意象标签
  • 白话对照分步出
初中 7–9

声律解剖

平仄
  • 方向 B 信息图
  • 平仄/韵脚/意象上线
  • 结构化精读
高中 10–12

意境 + 声律 + 情感弧

思故乡
  • 方向 A+B 融合
  • 意象结构 + 情感曲线
  • 高密度、学术克制
这只是校准样例。确认「设计感/现代审美」到不到位、哪个方向对味后,我再把这套方法规模化到全部内容类型(拼音/单词音标/化学结构/几何/受力图/时间轴…),每类都给 ≥2 异质方向 × 学段四档,汇总成实现 spec。
