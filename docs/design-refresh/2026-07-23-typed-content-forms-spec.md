# 特殊教育内容 · 超越教材的呈现形式设计目录

> **一句话定位**:不做「教材第二版」。把每一类需要专属呈现的教育内容,当作一个顶尖设计工作室接到的命题——在**教育正确**的前提下,给出**有设计感、现代、让学生想看**的呈现形态,并按学年分档。

---

## 0. 设计总纲(稳定核心)

### 0.1 目标——超越,不是还原
教材的排版是**印刷时代 + 成本约束 + 黑白纸面**的产物:古诗竖排宋体、拼音田字格、化学键线式扁平黑线、地图灰阶。它们是「正确但无聊」的最低保真。我们要的是**在保真之上再进一层**:
- **正确性是底线**,不是目标:平仄不能错、音标不能错、化学键角不能错、配平不能错。
- **设计感是目标**:每一类内容都有一套**专属视觉语法**,让学生一眼觉得「这个好看、我想看」,而不是「又是课本」。
- **现代学生审美**:参照的不是人教版,是他们每天在看的东西——优秀 App、数据可视化、动态海报、游戏 UI、短视频信息图。明亮、通透、有层次、有节奏、有一点点惊喜。

### 0.2 五条不可违背的地基(继承既有审美律)
1. **白为主**:近纯白地色,颜色只在物件层(继承 2026-07-22 白化令、粉紫禁令)。
2. **图辅文主 / 内容主体清晰**:炫技不能压过「学生要学的那个点」。
3. **正确性可核验**:符号、公式、音标、结构一律规范,错了就是废。
4. **分学段**:同一内容,低小到高中是四套气质,不是一套缩放(见 0.3)。
5. **反同质**(creation.md):每类内容的设计必须结构真异质,不是给所有内容套同一个「卡片+标题+accent」皮。

### 0.3 学段分档轴(四档,贯穿所有内容类型)
不是「字号大小」的区别,是**认知负荷 × 脚手架 × 抽象度 × 情绪气质**四轴同时移动:

| 学段 | 气质关键词 | 脚手架 | 密度/抽象 | 视觉手法 |
|------|-----------|--------|----------|---------|
| **低小 1-2** | 玩心、具象、安全感 | 拼音注音、实物图、手把手 | 极低密度,一屏一点 | 大圆角、大留白、具象插画、暖色点缀、拟物 |
| **高小 3-6** | 好奇、探索、成就感 | 图示为主、开始去脚手架 | 中低密度,分步 | 明快、模块化、轻游戏化、信息图起步 |
| **初中 7-9** | 系统、逻辑、身份认同 | 结构化、符号规范上线 | 中高密度,多信息并置 | 编辑设计、数据可视化、克制的酷 |
| **高中 10-12** | 严谨、审美成熟、效率 | 规范符号、推导完整 | 高密度,学术克制 | 极简高级、精密排版、专业级图表 |

**分档不改内容,改呈现的「说话方式」**:古诗对低小是「一幅会动的画配几个字」,对高中是「精密的意象结构 + 平仄声律可视化」。

### 0.4 呈现设计的产出模板(每个内容类型都按此给)
> ① 内容类型 & 教育内核(要学生 get 到的那个点)
> ② 常规教材形态(作为「要超越的对象」,一句话)
> ③ 超越设计(视觉语法:构图/字体/色彩/动效意图/交互意图)——**≥2 个异质方向**
> ④ 学段四档差异
> ⑤ 数据结构建议(contentSlots 需要哪些具名字段)
> ⑥ 现状(已有渲染器 / 缺口)& 实现优先级

### 0.5 方法论(creation.md 选用)
- **逆向渲染 / 第一性**:先问「这个内容的本质结构是什么」(古诗=意象+声律+情感弧;化学结构=原子拓扑+电子;音标=发音部位+口型),让本质结构直接驱动视觉,而不是套现成版式。
- **跨域移植**:把非教育领域的成熟视觉语言(唱片视觉、地铁图、分子动画、字幕排版、乐谱、代码编辑器)移植进来当骨架。
- **强制多方向 + 反同质自检**:每类 ≥2 个结构异质方向,过 Dribbble 化 / AI 平均感 / 模板污染 三道自检。

### 0.6 现状架构基线(2026-07-23 调研,决定新设计落哪、复用什么)
存在两条互不相通的内容管线,新设计必须先分清落点:

- **系统 A · mainline(现役主线)**:`LessonScene.contentSlots` 是无类型 `Record<string,string>`,渲染入口 `SceneTechniqueView.tsx`。**铁律:显式槽键触发,禁正则猜类型**。视觉母版极丰富(每幕型 5–10 母版),但**结构化内容槽只有三类**:`poemLines`(PoemDisplay)、`timelineEvents`(TimelineEventsView)、`dialogueScript`(DialogueScriptView)。其余学科专业内容一律降级为通用文字卡(StaticBoard/BoardTextBlock)或整幅 AI 生图。
- **系统 B · v2(未接入 mainline)**:`VisualSpec` + `contentType`(C01–C15)+ ~20 个专属渲染器(`concept-map`/`math-model`[number-line/coordinate/ratio-bar/geometry]/`data-chart`[bar/line/table]/`experiment-board`/ConceptVisual 家族)。结构承载丰富,但视觉偏功能性(非「设计感」),且是另一条**未与主线打通**的管线。
- **数学公式**:MathJax(非 KaTeX),支持 `\(…\)`/`\[…\]`/`$…$`。数理化生成期已要求行内 LaTeX。
- **假专属渲染警示**:`RefractionSimulation`/`LabelledDiagram`/`DraggableModel` 共用**写死的折射光路 SVG**,换任何其它实验/图都画错——不是通用能力,是占位。
- **学段分档基建齐全**:`BAND_FACTORS`(master-routing 母版加权)、`FIDELITY_MATRIX`(image-fidelity 配图保真档)、`GradeAdaptationProfile`(languageDensity/boardDensity 等)、`toneRulesFor`。gradeBand 挂课级(幕级无独立)。

**落地策略结论**:
1. 新专属内容一律走**系统 A 的显式槽键模式**(照 timeline/dialogue 新增 contentSlots 键 + 在 SceneTechniqueView 派发),不碰正则猜测。
2. **复用系统 B 的数据结构与解析器**(VisualSpec/parseXxx),**视觉层全部按本目录重新设计**到现代审美——不照搬系统 B 的功能性外观。
3. 生成期:在 `fill-scenes.ts` 的 `CONTENT_FORM_RULES` 扩展学科规则,让 LLM 主动产出新槽键;渲染端只认键。

### 0.7 位图 vs 矢量精绘的分工(2026-07-23 用户校准:够档次)
**扁平 SVG 线描画不出档次。** 凡是「示意插画」性质的视觉,必须走**生成位图**(写实 or 风格化,接 image-fidelity 管线),而不是手绘 SVG 线条。矢量/HTML 只留给**数据精确**性质的元素。分工铁律:

| 走【生成位图】(写实/风格化,image pipeline) | 留【矢量/HTML 精绘】(SVG/CSS) |
|---|---|
| 具象事物:器官/细胞/动植物、实验器材与装置、历史场景/人物、艺术作品、地貌实景、物理情境实物(小车/斜面/透镜) | 数据精确符号:平仄○●、拼音调值曲线、坐标轴/函数曲线、统计图表、数轴、Punnett 方格、化学键线式/结构式、时间轴刻度、乐谱 |
| 需要质感/光影/氛围/美感撑「想看」的意境类(古诗意境、星夜) | 需要像素级对齐/可核验/随数据变的(角度标注、比例、配平计数) |
| 判据:这东西「长什么样」重要、越真越好 | 判据:这东西「结构/数值」重要、必须精确无误 |

- **混合是常态**:一张幻灯常是「生成位图底 + 矢量精绘标注层」。如物理受力图 = 真实小车斜面位图(生成) + 精确矢量力箭头/角度(SVG 叠加);生物结构图 = 写实器官位图(生成) + 矢量引线标注;古诗律 = 无位图(纯数据),古诗境 = 氛围位图 + 竖排字。
- **画廊 mock 里的 SVG 线描,凡属左栏性质的,都是占位**,实现时替换为生成位图。设计文档需逐类标注每个视觉元素归哪一栏 + 生成位图的画风/prompt 方向 + 叠加的矢量层。
- 生图走既有 `imageFidelity` 三档(diagram-accurate 精确示意图 / stylized-teaching 风格化教学插画 / atmosphere 氛围),按学段学科选档:低龄偏 stylized 可爱写实,高中偏 diagram-accurate 专业精密。
- **白为主的边界(2026-07-23 用户拍板)**:白为主约束的是**幕面/UI 底色**,不是位图内容。**氛围类位图允许深色**(如古诗月夜),只要**收在图卡内、幕面其余留白**即可,不强求位图本身全白。即「深底只在图卡内,不整幅出血占满幕」。
- 校准样例:`2026-07-23-typed-content/raster-upgrade-demo.html`(眼球写实底+矢量引线 / 斜面写实底+矢量力箭头 / 古诗意境氛围卡)+ `_raster/{eye,incline,poem-mood}.png`,gpt-image-2 实拍,证明档位。

### 0.8 精准度打磨(用户校准:很多设计需要提精度)
「大方向可以」但细节精度要提。逐类过一遍:
- **正确性精度**:标注位置、角度数值、比例尺、刻度、配平系数、音标符号——不能「差不多」,要像专业教材/权威图鉴那样准。
- **视觉精度**:对齐、间距节奏、层级、留白、字重字号成体系;引线要真连到位(古诗 callout 曾犯断连);SVG/位图不溢出不裁切。
- **信息精度**:每个元素都有存在理由,去掉装饰性噪音;标号/编号只在真有序时用。
- 这是实现阶段每个 typed 渲染器的验收项,不是可选。
