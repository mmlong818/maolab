## 0. 方法论声明（creation.md 强制项）

本提案组合三个方法论：

1. **AestheticTheory（美学结构）**——诊断出的不是「缺装饰」而是缺美学结构：无类型音阶、无构图网格、token 分层不足以撑多层合成。先修结构再谈风格。
2. **Semiotics（符号系统）**——signature 风格的本质是可识别符号语言（蓝图=白描线稿+电光青，水墨=朱砂印+直角引号），每个方向必须定义自己的符号集，而非换色板。
3. **MorphologicalAnalysis（形态组合）**——维持「风格管质感 × 版式管结构」正交架构，把新资源拆解为可组合维度（token 阶梯 × 构图母版 × 排印规则 × 质感技法 × 字体气质），组合空间即扩充空间。

## 2. 开源资源核实清单（三路调研，28 仓库实开核验）

### 采纳为「构图母版」来源
- **touying-typ/touying**（2.2k★，MIT，2026-06 活跃）：唯一为讲课而非路演设计的主题体系。Stargazer 定理卡片（深题头+浅正文+渐变分隔）、渐进目录（讲到哪节哪节亮）、Focus 全出血强调幕、Dewdrop 侧边栏/迷你幻灯条双导航——直接映射教学版式。
- **slidevjs/themes**（213★，MIT，素材 CC BY-NC-SA 只参考构图）：官方「同一版式做多套密度变体」策略 = 106 版式扩容方法论。

### 采纳为「配色算法」来源
- **evilmartians/harmony**（MIT）：OKLCH 等亮度阶梯 + APCA 对比度约束派生色板——治「肉眼挑 hex 导致各档失衡」的病根。
- **radix-ui/colors**（1.6k★，MIT）：12 级色阶职责划分（1-2 底/3-5 组件/6-8 边框/9-10 实底/11-12 文字），偷分层逻辑不偷色相。
- **jnsahaj/tweakcn**（10k★，Apache-2.0）：非紫色系预设做情绪板校准（vintage-paper #a67c52/#f5f1e6、kodama-grove 苔绿牛皮纸、doom-64 克制撞色）。

### 采纳为「质感技法」来源
- **enyineer/slidev-theme-neocarbon**（MIT）：电影质感暗场全套——feTurbulence 胶片颗粒、暗角、发光渐变缘、玻璃拟态节制用法。
- **rnd195/marp-community-themes** Rosé Pine 三变体：同一叙事色板拆日/月/黎明三态——风格包从单态到多态的扩容公式。Graph Paper：网格装饰不媚俗的正面案例（极细极浅+大留白）。

### 采纳为「中文排印/字体/文化」来源
- **sivan/heti**（6.7k★，MIT）：标点挤压数值表（-0.5em/-0.25em、行高 1.5/2.25、字距三档）——现有排印规则漏掉的一层。
- **ethantw/Han**（2.5k★，MIT）：悬挂/挤压完整实现，只抄数值不抄 JS 包裹机制。
- **lxgw/LxgwNeoZhiSong**（2026-07 活跃）+ **takushun-wu/WenJinMincho**（OFL）：文史新宋体选项；**KonghaYao/cn-font-split**（Apache-2.0）：woff2 子集化基建（自托管字体的前置条件）。
- **zerosoul/chinese-colors**（2.7k★，MIT）+ **nevertoday/zhongguo-traditional-colors**（MIT，2026-07 活跃）：传统色 hex+色名+典故数据，风格包色板命名的文化弹药。
- **OpenWebGAL/WebGAL**（3.9k★，MPL-2.0）：对白框构图公式（胶囊 radius calc(h/2)、名牌 -68px 叠压、双层文字渲染 background-clip:text + text-stroke）——galgame 名牌带的源码级参照。

### 排除
- reveal.js 主题生态（最高 19★，2015 年审美）、Aceternity（无源码仓库）、originui（仓库已转让断线）、neobrutalism 整体采用（新的平均感，仅局部互动件可用）、紫渐变玻璃拟态（一票否）。

## 3. 三个设计方向（结构真异质）

### 方向 A 「剧场刊物」 Editorial Stage
- **本质**：版式结构革命——治「构图不驾驭画布 + 内容单元单一」。
- **情绪锚点**：翻开一本为这节课单独排版的杂志专题；郑重、被款待感。
- **符号集**：非对称网格（内容 62/38 分栏，故意破格一处）、定理卡片（Stargazer 深题头公式）、渐进目录、超大页眉序号（本幕号做 240px 装饰字）、细规则线系统。
- **改什么**：版式库新增一族「编辑部构图母版」（开场幕满版报头/定理卡/焦点全出血/侧栏批注体），逐步替换现有排排坐卡片；类型音阶落地（display 48-64 / heading 32 / body 24 / caption 16 的中文校准版）。
- **风险**：与 galgame 立绘的气质张力，需用「杂志插页」逻辑安放立绘。
- **来源**：Touying Stargazer/Dewdrop + huly 非对称构图 + Geist 排版命名法。

### 方向 B 「电影舞台」 Cinematic Stage
- **本质**：质感与光的系统——治「装饰存在感≈0 + 暗场廉价感」。
- **情绪锚点**：灯光暗下来，课开演了；剧场的仪式感。
- **符号集**：胶片颗粒 + 暗角 + 发光缘（neocarbon 三件套）、每风格包拆日/月/黎明三态（Rosé Pine 公式，开场用日态、高潮幕切黄昏、收束回夜态——课的节奏进入光的节奏）、WebGAL 级对白框（胶囊构图+双层文字）。
- **改什么**：装饰库从 4 缘饰升级为「光系统」（底光/颗粒/暗角/辉光四层可组合）；风格包 palette 增加 mood 三态派生；DialogueLayer 对白框按 WebGAL 公式重构。
- **风险**：过度电影化伤教学可读性——硬底线：正文对比度不因质感层下降（APCA 锁定）。
- **来源**：neocarbon + Rosé Pine 三变体 + WebGAL textbox 源码。

### 方向 C 「文房新谱」 Chinese Literati System
- **本质**：中文原生的排印/字体/文化系统——国际竞品做不到的独有 signature。
- **情绪锚点**：老师案头的文房，被认真对待的汉字；安静的骄傲。
- **符号集**：字体气质分工（明朝体标题=文史高年级、霞鹜楷=低学段、思源黑=理科正文、Sarasa 等宽=公式代码）、标点挤压/悬挂（heti 数值级）、传统色命名体系（风格包色板全部改用真实传统色名+典故，如蓝图的电光青→「窃蓝」、水墨的朱砂→「银朱」）、直角引号/着重号做强调语言（替代英文斜体思维）。
- **改什么**：字体管线（cn-font-split 子集化 + 按风格包挂载 display 字体）；排印规则层补标点挤压；色板数据接传统色库；新风格包「文房」孵化（LxgwNeoZhiSong + 宣纸底 + 传统色）。
- **风险**：字体体积（子集化必须先行）；低学段亲和力需靠霞鹜楷平衡。
- **来源**：heti/Han 数值 + LxgwNeoZhiSong/WenJinMincho + chinese-colors 双库 + clreq。

### 推荐组合路线
三方向作用于不同层（A=构图、B=质感光影、C=排印文化），**不互斥，分期全做**；但每期一个主攻，避免平均用力回到平均感：
1. **第一期（推荐先做 A）**：构图是当前最痛（40% 空白/排排坐），且 A 的编辑部构图母版能直接扩充版式库——最贴合本次指令「持续扩充格式版式」。
2. 第二期 B：地基修缮已埋噪点/暗角种子，B 把它长成系统。
3. 第三期 C：字体子集化基建就绪后上，孵化「文房」signature。

## 4. 「模板 → 版式库」持续扩充管线（机制设计）

一次性搬模板会再次腐化；建立机制：

1. **来源登记**：`docs/design-refresh/sources.md` 维护已核验仓库清单（本文件 §2 为首批），每季度跑一次调研代理刷新（关键词：slidev/marp/typst theme、design tokens、中文排版，按 star 增速+最近提交过滤）。
2. **拆解协议**：每个新模板按五维拆解入库——token 阶梯 / 构图母版 / 排印规则 / 质感技法 / 字体气质。只入维度值，不入代码。
3. **落地路径**：构图母版 → 版式库新 layout（走既有 registry whenToUse/fieldsDoc 三件套）；质感技法 → 装饰库新轴值；token 阶梯 → OKLCH 重派生脚本的输入。
4. **验收闸门**：新版式/风格入库前过反同质化自检（§5）+ 三课截图对照（跨学段跨学科各一）。

## 5. 反同质化自检（creation.md 强制项）

- ✅ 无 Dribbble 化：拒绝紫渐变玻璃拟态、拒绝整体 neobrutalism（两者都是新平均感）
- ✅ 无模板污染：只拆维度值不搬代码/资产（CC BY-NC-SA 素材仅参考构图）
- ✅ 结构真异质：A 改构图层、B 改质感层、C 改排印层——不是三套换皮配色
- ✅ 创作者偏见保留：剧场世界观（幕/立绘/名牌）是稳定核心，所有方向都为它服务而非抹平它
- ✅ 人类兼容性：教学可读性是硬底线（APCA 锁定、字距不照搬 galgame 0.2em、低学段亲和力约束）
- ✅ 文化特征注入：方向 C 整体、方向 A/B 的中文类型音阶校准
