## 恢复方式

归档目录内的 `manifest.json` 记录每一项的原始相对路径、归档位置、文件数、字节数和原因。恢复前先停止 maolab 服务，再把所需条目移回 `originalPath`。`app/.next` 无需恢复，重新执行构建即可生成。

归档是本机资料，不随 Git 远端分发；远端仓库只保留这份位置说明和当前项目所需文件。
