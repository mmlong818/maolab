## 二、各幕型正确呈现形态(结构层规范,方向无关)

通用铁律(承接 project-redesign §4.8 与舞台定档规则):

1. **立绘列让位**:无图幕出立绘时,内容区必须为立绘侧让出 ≤24% 宽的立绘列,内容在余下区域排版;内容密集(source-reading/worked-example)时角色只能走字幕带,不出立绘。
2. **槽位必上屏**:每种 sceneType 的核心 contentSlots(见 fill-scenes SCENE_ROLES 约束)必须有渲染出口——有图时以浮层卡呈现,无图时以版式主体呈现。禁止"生成了但从不显示"。
3. **胶囊限额与避让**:图上浮层板书 ≤3 条;位置从固定左上改为按图 safe-zone 锚定(生成 prompt 已预留底部 20%,浮层板书应优先用左上 25% 象限,超限收进"图例卡"折叠)。
4. **图与文本职责分离**:配图承担"看",浮层文字只做锚点(≤12 字/条);完整表述交给字幕带与板书卡,不在图上堆句子。

### 逐幕型

| sceneType | 呈现形态 | 图 | 角色层 |
|---|---|---|---|
| source-reading 开场 | **章节扉页**:大标题 + 学习路线图(3 步横向 stepper,替代 3 条满宽条) + 视觉锚(学科主题立绘/封面资产,cast/subject 矩阵现成) | 用现成学科立绘资产,不烧新图 | 无角色(维持) |
| visual-observation 观察 | **满幅挂图**(现 ImageDrivenScene 保留):图 letterbox 满幅,胶囊 ≤3 条编号锚点 | 必出图(维持) | 旁白字幕(维持) |
| concept-build 建概念 | **定义卡版式**(新组件):中央核心表述大字卡(学科强调色描边),下方正例便签卡错位放置;立绘列让位 | 不出图(定义以字为主) | 老师立绘于让位列 |
| contrast 辨析 | **图底 + 两栏浮层**(改造):有图时图为底,misconception(暖)/correction(青)两张浮层卡左右下沉排布,不再只剩胶囊 | 必出图(维持) | 学生立绘 + 字幕(维持) |
| worked-example 例题 | **题面卡 + 步骤回放**(改造 StepReplay):顶部固定题面卡(problem 槽),下方编号步骤卡逐条;内容密集,无立绘 | 不出图 | 旁白字幕 |
| practice 练习 | **任务卡 + 反馈翻转**(新组件):上任务卡(task 槽),下反馈卡默认半掩("先自己答"),节拍 reveal 后展开(feedback 槽);立绘列让位 | 不出图 | 学生立绘于让位列 |
| recap 收束 | **满幅路径图 + 路径条**:图维持;胶囊改为横向路径 stepper 贴字幕带上沿,与图内元素脱开 | 必出图(维持) | 老师立绘 + 字幕(维持) |

配套生成层小改:fill-scenes 给 concept-build/worked-example/practice 的 prompt 注明"本幕无配图,visualFocus 不得写'示意图/分类框'类词"。

## 三、审美方向(3 选 1,结构规范之上的皮肤层)

> 方法论:Semiotics + AestheticTheory(A) / 瑞士网格 + HumanCenteredDesign(B) / NarrativeDesign 镜头语言 + GameDesign(C)。
> 稳定核心(三方向共守):暖纸底色系传承、卡司立绘体系不动、16:9 满幅教学内容、字幕带唯一预留、学科分色。

### 方向 A · 教具实物感(Museum / 标本馆)

一切 UI 元素都是"教室里的实物":板书条 = 别针别住的纸签,图 = 幕布上的挂图(细边框 + 微透视投影),路径 stepper = 麻绳串卡片,反馈卡 = 翻开的对折纸。纸纹理、胶带角、手写体点缀标签。
- 差异点:材质语言。数字感最弱,记忆点最强,和水彩立绘/水彩配图天然同源。
- 风险:纹理资产要做一套;做过头变"手账风"损伤严肃感(护栏:纹理透明度 ≤8%,手写体只用于人名/批注)。
- 成本:中。CSS 纹理 + 少量 SVG 装饰件。

### 方向 B · 杂志编辑排版(Editorial)

以印刷网格为骨:12 栏网格,大号衬线中文标题(思源宋/霞鹜文楷),重留白,正文栅格对齐;每学科一个强调色(现 backdrop 渐变收敛为纸白 + 强调色细节);胶囊改为页边注(margin note),页码/章节角标常驻。图按版式占位:整版/半版/三分版三档。
- 差异点:版式系统。最"跟上新审美"(编辑排版是近年教育产品主流升级方向),信息层级最清晰。
- 风险:与 galgame 立绘层气质有张力(护栏:立绘幕维持现暖底,编辑网格只管内容板);衬线字体加载体积。
- 成本:中低。纯排版重构,无新资产。

### 方向 C · 舞台景深分层(Diorama)

强化既有舞台隐喻:背景从单渐变升级为三平面(远景幕布微暗角 / 中景内容板带景深阴影 / 前景立绘),每类幕型对应一种"机位"——开场是全景,观察是推近特写,辨析是对切镜头,收束是拉远。幕间切换带 300ms 景深过渡。
- 差异点:空间构成与镜头语言。上课的"剧场感"最强,与广播剧/语音路线最契合。
- 风险:动效工程量;低端机性能;做过头喧宾夺主(护栏:prefers-reduced-motion 全静态降级,阴影两档封顶)。
- 成本:中高。

### 反同质化自检

- A 不是"加个纸纹理的拟物复古"——它把每类 UI 件重新指认为具体教具,结构随材质变(别针签是错位排布,不是圆角卡换皮)。
- B 不是"Dribbble 化大留白"——网格服务信息层级(题面/步骤/反馈各占固定栏位),不是装饰性留白。
- C 不是"加动画"——机位是每幕型的固定叙事语法,静止帧也成立。
- 三者结构真异质:A 变材质语言,B 变版式系统,C 变空间构成,不可互相换皮得到。

## 三之二、四轴版式基因库(2026-07-13 已落地)

用户定档:不选单一方向,要"至少 100 种图文立绘字幕混合方式"。落地为
`lib/mainline/presentation/composition.ts`:

- 四条正交轴:图形态(6) × 文字形态(8) × 立绘位(3,由 dialogueLayout 显式派生) × 字幕形态(3)
- 合法性规则过滤后 **170 种组合**(单测断言 ≥100);每幕按幕型偏好 + scene.id 哈希确定性轮换,同类型多幕自动错开版式
- 3:2 配图在 16:9 舞台的左右余带显式化为「侧栏卡位」——文字卡下侧栏(立绘对侧),不再压图;满幅裁切/上带/贴边共 5 种图形态轮换
- 同步修复:A1 立绘让位(spritePad)、A2 辨析误区/修正双卡上屏(RailCards)、A3 题面/任务/反馈上屏(WorkedExampleView/PracticeView/ConceptBuildView 按 sceneType 显式分派)、A4 胶囊 ≤3 条+折叠、A5 生成图 prompt 改满幅构图(旧图不受影响,新课生效)
- 三个审美方向(A/B/C)仍作为组合系统之上的皮肤层备选

## 四、推荐与实施顺序

推荐 **B 为主、A 做点缀**(编辑网格定骨,实物签只用于板书胶囊与人名贴纸):B 直接解决"排版不够美观"的主诉且成本最低,A 的纸签点缀保住与水彩立绘的温度;C 留给上课模式做增强(景深过渡可后补,不阻塞)。

实施顺序(无论选哪个方向,前两步相同):

1. **P0 结构修复**(A1-A5):mainline theme token 先行(`lib/mainline/presentation-tokens.ts`:ink/paper/accent×学科/radius/shadow 三档/字号阶) → 立绘列让位规则 → contrast 图底两栏浮层 → worked-example 题面卡 → practice 任务/反馈卡 → 胶囊限额避让 → fill-scenes prompt 补"无图幕禁写示意图"。
2. **P1 开场扉页 + StaticBoard 退役**:concept-build 定义卡组件落地,开场幕路线图 + 学科立绘锚。
3. **P2 选定方向的皮肤层**:token 换值 + 方向专属装饰件。
