# maolab 内容媒介化设计 v1（表现形式扩张）

> 2026-06-10 · 用户指令：学习内容能不能变成一首歌、一个故事漫画……
> 本质：同一份结构化课程内容（KP + atoms + 人设），演绎成不同**作品形态**。
> 方法论：NarrativeDesign（媒介叙事语法）+ SCAMPER（内容重组）+ HumanCenteredDesign（媒介选择匹配学段与记忆目标）。

## 0. 稳定核心

- **内容同源**：所有媒介从同一 course（KP/atoms/objectives）演绎，知识正确性继承自主管线，媒介只换"叙事语法"不改事实
- **人设连续**：老师与 4 个同学是跨媒介角色（漫画里的龙老师=课堂里的龙老师，声音/口头禅一致）——这是别家没有的资产
- **媒介有教学动机**：歌谣=记忆编码、漫画=情境化叙事、播客=碎片时间复习，不为炫技而媒介化
