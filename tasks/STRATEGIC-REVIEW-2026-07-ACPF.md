# 战略对标:ACPF「AI 教材内容生产工厂」× maolab 卖点分析

日期:2026-07-13
对标物:ACPF v2.0(中学)/ v3.0(1-4 年级)/ v3.5(5-6 年级)+ 补丁包(圣经层 + 事实核查层)——一套多 Agent 提示词流水线设计,产出图文教材 + 配图 prompt。
方法论:JobsToBeDone(用户雇产品做什么)× SystemsThinking(资产与飞轮)× NarrativeDesign(课堂即剧场)。

## 0. 一句话结论

ACPF 是内容工厂,产出「给所有人的同一本教材」;maolab 是课堂剧场,产出「此刻正在发生的一堂课」。
ACPF 自己承认:提示词流水线最容易被抄,壁垒在数据资产。maolab 的对应壁垒是**可运行的呈现引擎 + 真检判例库**,再叠上 ACPF 没有的三个维度:在场(社会性)、时间性、学情闭环。

## 1. ACPF 系统速写

- 流水线:Agent -1(学科/学段路由)→ 0(考点 Deep-Dive/Fast-Track 价值分流)→ A(组件化骨架/Render_Queue)→ B(组件渲染正文)→ C(风格质检,循环 5 次强制放行)→ D(Midjourney prompt CSV)。
- 学段心理路由:1-4 游戏化冒险(知识=道具,禁抽象);5-6 酷感胜任(Anti-Cringe,档案/蓝图/侦探);中学学术双模(STEM 隐喻桥 / HUMANITIES 视角切换)。
- 补丁包:Series Bible(世界观/角色卡/隐喻注册表/剧情弧线/进度状态,人审入库)+ Agent E 事实核查(断言三级分级 FATAL/MISLEADING/IMPRECISE,隐喻白名单审计,误概念库,FATAL 不许强制放行)。
- 其自认护城河:课标知识图谱、隐喻注册表+误概念库、Series Bible 三张表。

## 2. maolab 三大卖点(结构真异质)

### 卖点 A · 「他们造教材,我们开课」——形态卖点

ACPF 终点是更好看的**讲义**;maolab 终点是**可上演的课**。差异是媒介级的,不可换皮:

- **时间性**:节目单、节拍、语音/TTS、幕间推进——课有时间轴,教材没有。
- **社会性**:ACPF 的 Error_Trap 是纸上的「❌ 常见误区」警告框;maolab 的误概念是**同学当场犯出来、老师当场纠正的剧情事件**(vicarious learning,替代学习)。这是 ACPF 整套体系缺席的维度。
- **在场感**:立绘、字幕带、名牌、学科分色舞台——孩子不是「读懂了」,是「上完了一节有人陪的课」。

情绪锚点:陪伴感。一句话:**内容工厂生产版本,我们生产课堂。**

### 卖点 B · 「提示词 vs 渲染引擎」——工程壁垒卖点

ACPF 视觉层 = 一张 Midjourney prompt CSV;质检 = 提示词愿望清单。maolab 对应的是被测试锁定的呈现引擎:

- 170 版式基因 × 学科×3 mood 配色库 × 呈现原子六库 × 5 signature 风格包,确定性解析(课程盐哈希、课级 mood 一致),回归测试锁行为。
- 8 轮全量真检 = 60 条缺陷按根因聚类修复的**审美判例库**。抄 prompt 抄不走引擎与判例。

情绪锚点:专业信任感。一句话:**别人卖印刷配方,我们卖皮克斯式渲染管线。**

### 卖点 C · 「零接触批量 vs 学情闭环」——数据卖点

ACPF 设计哲学第一条是 Zero-Touch:生产过程无人参与、产出静态品、**没有学习者反馈回路**。maolab 库内已有 classroom 实时引擎(互动/测验/自适应)与 user-profile 学情包;闭环尚未接入 mainline,但架构插座已留好,ACPF 的架构里没有这个插座。

情绪锚点:被看见。一句话:**每个学生上的是自己的那堂课。**(对外表述用「已留好插座」,不说「已完成」)

### 候选卖点 D · 「卡司即 IP」

maolab 的卡司矩阵(固定人设跨课一致)+ signature 风格包(视觉一致)= Series Bible 的 Character_Canon 已经落地了一半;补上跨课剧情/进度即可升格为第四卖点。归入 v4 总方案(见 docs/v4-master-plan-2026-07-13.md)。

## 3. 值得抄进来的三件事(差距清单)

1. **隐喻注册表 + 误概念库**:我们有指图闸门、跨幕一致性注入,但没有「隐喻白名单 + Known_Limits 强制拆穿边界」。其起始误概念清单(机翼等时说、电流用光、拉马克目的论、乘法变大等 10 条)可直接采用。
2. **学段叙事路由**:我们 gradeBand→signature 风格包已是其 Visual_Style 路由的落地版,缺「语气/叙事轴」(1-4 禁抽象与说教腔 / 5-6 Anti-Cringe 禁低幼 / 中学禁鸡汤)——应作为生成期约束 + 闸门禁词表。
3. **事实核查的分级与不放行原则**:断言三级(FATAL/MISLEADING/IMPRECISE)+「事实问题绝不强制放行、修不好惊动人类」——与我们 qualityStatus=blocked 机制同构,可直接扩展。

## 4. 对外话术分配

- 对用户/市场:主打卖点 A(形态差异最易感知)。
- 对投资人/竞争分析:主打卖点 B(壁垒最硬、证据最足:代码 + 测试 + 8 轮真检报告)。
- 路线图叙事:卖点 C + D(如实标注进度)。

## 5. 反同质化自检

- A 不是「我们也做游戏化」——ACPF 的游戏化是文本皮肤(定义改叫魔法),我们的差异是媒介本身(时间轴 + 多角色在场)。
- B 不是「我们质量更好」的空话——是可验证资产。
- C 不是「AI 个性化」行业平均话术——锚定在 ACPF 明文放弃的 Zero-Touch 反面。
